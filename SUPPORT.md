# 支持政策

当前项目处于规格与设计阶段，没有公开 Release 或可运行应用，因此暂无可支持的应用版本。

首个公开 Release 后，项目只支持最新的应用正式稳定发行。应用测试发行（包括 beta、preview 和其他预发布版本）以及更早的正式稳定发行不在公开支持范围；它们可以继续作为历史资料或测试反馈对象，但不构成支持承诺。

## Support Policy

The project is currently in the specification and design phase. There is no public Release or runnable application, so no application version is supported yet.

After the first public Release, support covers only the latest application formal stable release. Test releases, including beta, preview, and other pre-releases, and earlier formal stable releases are outside the public support scope.
