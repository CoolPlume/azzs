# 硬件信息表只呈现可解释的直接事实

Status: proposed
Date: 2026-08-23
Related: ADR-0008, ADR-0009, ADR-0049, ADR-0050

## Context

0.1.1 实测制品 `f2f1998` 将存储接口、PCIe 代际、NAND 颗粒和资料识别推断拼入硬件字符串，并把未知介质显示为“未分类物理磁盘”；显示器摘要还把 EDID 刷新率上限写成说明性标签。该提交是正式 0.1.1 基线 `04eeb5a` 的祖先。用户需要机型、Windows 版本和设备信息统一可复制呈现，但不需要这些推断和未分类记录。

## Decision

- 硬件页面使用统一“项目 | 信息”表，包含机型、Windows 版本和已确认硬件类别；固定摘要无事实显示“未识别”，多实例类别无记录隐藏。
- CPU 摘要固定显示性能核、能效核和低功耗能效核三段；仅当 Windows 可靠确认两类或三类拓扑且总数一致时显示数值，缺失类别为 `0`；拓扑不可获取、单一 `EfficiencyClass` 或计数不一致时三段均显示“未识别”，不猜测或以 `0` 代替未知。
- 未分类物理磁盘不进入普通表格或用户可见摘要；未知物理性继续按 ADR-0049 fail-closed。
- 显示器摘要固定包含型号、分辨率、Hz 数值、内建/外接状态和英寸，采用“分辨率；Hz；内建/外接；英寸”的固定顺序短文本；每个无法可靠取得的槽位显示对应“未识别”字段，不猜测或省略。英寸优先由可验证的 EDID 物理尺寸换算；仅当 EDID 缺失、无效或冲突时，才可回退到活动 WMI 物理尺寸，且必须按完整 PNP 实例精确匹配，不得按同型号推断或共享。
- 固态硬盘普通展示只保留型号、容量等直接观测事实，不显示接口、PCIe、NAND 颗粒、资料识别或来源研究推断。
- 硬件文字可选择复制，并提供复制本节命令；普通页面不显示序列号、唯一设备标识、完整 PNP 实例标识、原始 EDID 或其他可追踪资料。

## Consequences

- 页面更容易扫描、复制和解释，且不会把研究推断伪装成 Windows 直接观测。
- 诊断如需保存结构化事实，必须与普通展示分离并遵守脱敏边界。
- 需要从正式 0.1.1 基线 `04eeb5a` 对照 `f2f1998` 的实测展示，并增加多显示器、未知 EDID 和未识别行测试。

## Rejected alternatives

- 保留所有推断文本：信息密度高但语义和证据来源混杂，用户明确不需要。
- 将未知介质统一命名为物理磁盘：违反 ADR-0049 的 fail-closed 边界。
- 由页面各自删减或过滤：会重新形成多份硬件事实。
