# 硬件信息表只呈现可解释的直接事实

Status: accepted
Date: 2026-08-25
Related: ADR-0008, ADR-0009, ADR-0049, ADR-0050

## Context

0.1.1 实测制品 `f2f1998` 将存储接口、PCIe 代际、NAND 颗粒和资料识别推断拼入硬件字符串，并把未知介质显示为“未分类物理磁盘”；显示器摘要还把 EDID 刷新率上限写成说明性标签。该提交是正式 0.1.1 基线 `04eeb5a` 的祖先。用户需要机型、Windows 版本和设备信息统一可复制呈现，但不需要这些推断和未分类记录。

## Decision

- 硬件页面使用统一“项目 | 信息”表，包含机型、Windows 版本和已确认硬件类别；键盘、鼠标和触控板是独立类别。固定摘要无事实显示“未识别”，多实例类别无记录隐藏。
- CPU 摘要固定显示中文的性能核、能效核和低功耗能效核三段；仅当 Windows 可靠确认两类或三类拓扑且总数一致时显示 `N性能核+N能效核+N低功耗能效核`，缺失类别明确显示 `0`，不得因零值省略。拓扑不可获取、单一 `EfficiencyClass` 或计数不一致时三段均显示“未识别”，不猜测或以 `0` 代替未知。
- 未分类物理磁盘不进入普通表格或用户可见摘要；未知物理性继续按 ADR-0049 fail-closed。
- 显示器摘要固定包含型号，以及括号中的分辨率、刷新率（Hz 数值）、内建/外接状态和英寸尺寸四槽，采用“分辨率；Hz；内建/外接；英寸”的固定顺序短文本；每个无法可靠取得的槽位显示对应“未识别”字段，不猜测或省略。英寸优先由可验证的 EDID 物理尺寸换算；仅当 EDID 缺失、无效或冲突时，才可回退到活动 WMI 物理尺寸，且必须按完整 PNP 实例精确匹配，不得按同型号推断或共享。
- 核显的模型、架构及 CU/EU/Xe 只在各自有可靠事实时显示；独显不显示计算单元或共享显存。GPU 板卡厂商同样只显示可靠观测事实，不从型号、泛化 WMI 文本或资料库补全。
- 普通页面的设备型号移除精确的 `(R)` 和 `(TM)` 商标标记；容量从可靠字节事实生成一份规范化文本，不保留型号中的冲突容量。内存品牌只有在制造商或可靠部件身份明确指向 Crucial 时才规范为“英睿达 Crucial”，不能把一般的 Micron/美光信息猜成 Crucial。
- 固态硬盘普通展示只保留型号、容量等直接观测事实，不显示接口、PCIe、NAND 颗粒、资料识别或来源研究推断。
- 键盘、鼠标和触控板只呈现可靠设备事实。键盘显示可靠的内建/外接状态，键数只在可靠观测时显示；内建键盘优先显示可靠设备、OEM 或驱动明确给出的具体类型，例如“蝶式键盘”“妙控键盘”。没有可靠类型时只显示“内建键盘”，不得由整机型号、WMI 名称或厂商品牌推断。
- 硬件文字可用鼠标或键盘选择后复制，但不存在“复制本节”按钮或命令；普通页面不显示序列号、唯一设备标识、完整 PNP 实例标识、原始 EDID 或其他可追踪资料。

## Consequences

- 页面更容易扫描、复制和解释，且不会把研究推断伪装成 Windows 直接观测。
- 诊断如需保存结构化事实，必须与普通展示分离并遵守脱敏边界。
- 需要从正式 0.1.1 基线 `04eeb5a` 对照 `f2f1998` 的实测展示，并增加多显示器、未知 EDID、CPU 零值、核显/独显边界、设备型号与容量规范化及输入设备可靠性测试。

## Rejected alternatives

- 保留所有推断文本：信息密度高但语义和证据来源混杂，用户明确不需要。
- 将未知介质统一命名为物理磁盘：违反 ADR-0049 的 fail-closed 边界。
- 由页面各自删减或过滤：会重新形成多份硬件事实。
- 增加“复制本节”按钮：会把标准选择复制扩展为并未确认的专用命令。
