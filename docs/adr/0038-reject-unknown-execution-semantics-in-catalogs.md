# 旧工作台拒绝未知执行语义的目录

Status: accepted
Date: 2026-08-10
Related: ADR-0011, ADR-0015, ADR-0023, ADR-0027, ADR-0028

目录可以向前增加未知的展示或说明内容，旧工作台可忽略它们；但未知模式版本，或会改变目标、来源、依赖、受控能力、执行、检测、恢复、重启、撤回或其他操作语义的目录内容，旧工作台必须拒绝整份候选目录，保留当前有效目录并提示更新工作台。此规则同样适用于内置目录、主动更新、调试模式手动导入和本机试用目录，不能因 `draft`、本机试用或局部错误处理而绕过。这样保留非执行内容的演进空间，同时确保旧版本不会按过期语义继续发起管理员操作。
