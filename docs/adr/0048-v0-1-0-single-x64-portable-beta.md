# 将 v0.1.0 限定为单 x64 便携 Beta

Status: accepted  
Date: 2026-08-21  
Related: ADR-0037, ADR-0045, ADR-0047

`v0.1.0` 是首个应用测试发行，而不是无后缀的应用正式稳定发行：应用版本保持 `0.1.0`，发布通道为 `prerelease`，Git tag 和 GitHub Release 使用 `v0.1.0`。本版本只交付 `standard-x64-portable`；ARM64、MSI/WiX、断网救援版、超大离线版以及安装、Repair、卸载和迁移生命周期均延期。版本分支为 `v0.1.0`，同一版本的实现、验证和发布准备都在该分支完成，通过门禁后以普通 merge 合入 `main`。

本版本仍须以生产组合根实现并启用全部 11 个正式软件目录项的受控来源解析、网络观察、存在检测、取得或下载、安装档案启动、完成观察和结果检测，并以自动化合同覆盖这些路径；目录必须处于 `release_state = "release"`。本机、虚拟机和其他候选设备均不执行真实第三方软件安装，发布说明和开发者证据必须明确写为“未实机验证”；mock 只作为回归证据，不能替代真实安装验证或关闭其延期事项。真实 Windows 11 x64 安装验证留给独立后续事项。

本决定只为 `v0.1.0` 限定地调整 ADR-0037、ADR-0045 与 ADR-0047 的适用范围：它们的八制品长期合同、自动发布权限设计和 x64 临时候选定义保持有效，不能被本次单制品 Beta 冒充完成。分支通过本版本门禁并合入 `main` 后，可以直接人工创建 GitHub prerelease、`v0.1.0` tag 和唯一的 `standard-x64-portable` 资产；不新增带写权限的 GitHub Actions，公开分支、tag、Release 标题和说明不使用 `codex` 命名。
