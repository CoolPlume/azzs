# 固定三档发行的八制品矩阵

Status: accepted
Date: 2026-08-10
Related: ADR-0012, ADR-0030, ADR-0031, ADR-0036

首版发行分为标准版、断网救援版和超大离线版。标准版同时提供 x64 与 ARM64 的便携版和安装版；断网救援版、超大离线版各只提供 x64 与 ARM64 的便携版，因此共八个制品。三档内容和两种发行架构仍保持独立，内容差异只由构建清单决定；所有制品均自包含工作台运行时。此决定以救援与超大离线版主要用于一次性、可移动首装为前提，避免为大体积内容重复维护安装、卸载和升级链，取代 ADR-0012 的两档模型。
