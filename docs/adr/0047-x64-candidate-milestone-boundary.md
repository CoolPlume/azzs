# 将 x64 临时候选与八制品发行分开

Status: accepted  
Date: 2026-08-17  
Related: ADR-0037, ADR-0046

当前把标准版、断网救援版和超大离线版三个 x64 便携制品的资源布局、内容绑定和候选门禁收束为“x64 临时候选”这一非发布开发里程碑。该里程碑不是发行结论：它不替代或完成 ADR-0037 的八制品合同，不表示任何制品已经生成或验证，也不表示 ARM64、机器级安装版、WiX/MSI、安装生命周期、GitHub Release 或真实设备验收已经完成。ADR-0037 保持不变，事项 21 继续拥有完整八制品发行门禁。
