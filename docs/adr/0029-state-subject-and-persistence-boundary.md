# 限定状态主体与本机权威状态

Status: accepted
Date: 2026-08-10
Related: ADR-0004, ADR-0013, ADR-0014, ADR-0032

首版只支持交互登录用户使用自己的拆分管理员令牌，所有用户级记录按该状态主体隔离；替代管理员凭据场景明确拒绝。权威状态只存于本机 `ProgramData`，网络或可移动位置只承载软件包缓存；兼容窗口为发布链 N 与 N-1，旧版本遇到未知新模式保留字节并拒绝写入。

共享缓存只保证同一设备的多实例并发，不承诺多台设备共同写入网络共享。全机恢复记录、批次、当前目录、历史和紧急撤回信息可按设备共享；已保存草稿、未保存检查点和偏好按状态主体隔离，普通浏览和导出默认只显示当前状态主体与全机事实，跨用户诊断必须由用户明确发起并继续脱敏。

权威提交只有在新代次完成校验、刷新、同卷替换、重新读取校验且上一可信代次仍可回退后才算成功。每类状态独立版本化并使用写时复制；无法保持 N-1 兼容时，不得声称支持自动回退。未保存目录修改最多丢失 10 秒，并在应用失活和高风险操作前建立检查点；每个检查点记录基础代次，代次冲突不自动合并，保存或放弃先记录已消费状态再清理旧载荷。

日志、历史和恢复记录是独立聚合。并发清空日志先提交明确截止事件并切换到新日志段；磁盘不足时停止非关键日志并记录可检测缺口，绝不自动删除历史或恢复记录。权威提交无法安全落盘时必须失败，不得显示为已保存。

普通卸载或删除便携目录只移除程序资产，设备级状态继续按 ADR-0032 保留；显式清理本机数据须区分当前状态主体与全机数据，并在活动或待恢复状态存在时拒绝破坏性清理。持久化合同的完成证据必须说明其覆盖的介质、用户身份和版本组合，未覆盖的组合明确为不支持；未进行真实设备验证时只记录“未实机验证”。
