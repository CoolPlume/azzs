# 将 Apple 设计原则适配到 WinUI 3

Status: accepted

Windows 版采用 Apple 对清晰层级、即时反馈、空间连续、克制材质和用户掌控的设计原则，并采用 Emil Kowalski 的频率优先、目的驱动、快速可中断和性能友好动效方法，同时保留 WinUI 3、Fluent Design 与 Windows 平台惯例。项目把这些方法转换为 WinUI 3 的统一语义动效资源和验收规则，不照搬 Web/CSS 实现，也不仿制 macOS 标题栏、交通灯按钮、Dock 或手势优先交互；高频与键盘操作必须即时完成且不播放空间动效，精致动效只服务偶发浮层、状态和结果反馈。

界面同时遵从 Windows 每显示器 DPI、显示缩放和默认图形适配器选择；4K、225% 显示缩放与混合 DPI 多显示器是首版必达场景。图形能力不同或视觉增强不可用时可以回退为实体背景和静态反馈，但功能、信息、无障碍和业务结果不降级。
