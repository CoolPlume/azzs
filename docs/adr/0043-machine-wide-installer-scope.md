# 首版安装版只支持机器级作用域

Status: accepted
Date: 2026-08-10
Related: ADR-0029, ADR-0031, ADR-0032, ADR-0033

首版 x64 与 ARM64 安装版都只提供通过 UAC 安装到整台设备的机器级作用域，程序资产、安装登记、Repair 与普通卸载均为机器级；用户级偏好和可恢复输入仍按 ADR-0029 的状态主体隔离。首版不提供用户级安装版或同时支持两种作用域的双作用域安装器，便携版边界不变。

该决定使安装、升级、Repair、卸载和 x64 到 ARM64 迁移与 `ProgramData` 设备级状态保持一致，代价是没有管理员授权的用户不能安装安装版。
