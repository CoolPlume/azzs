# 紧急撤回跨越三类受控操作

Status: accepted  
Date: 2026-08-10  
Related: ADR-0024, ADR-0025, ADR-0035

项目确认严重风险后，有效紧急撤回信息统一阻止受影响、尚未开始的软件安装、系统优化和软件优化步骤，包含既有批次中尚未开始的步骤；已经开始或完成的操作、恢复记录和历史保留，不自动终止或撤销。普通目录更新、回退和本机试用目录都不能绕过该设备级规则。

这把原先只适用于软件优化的例外扩展为同一台管理员工作台上的一致安全边界，但不重新引入签名、摘要、来源真实性、provenance 或项目级信任门槛；紧急撤回只表达项目已知的操作风险，记录仍只保留可观察事实。
