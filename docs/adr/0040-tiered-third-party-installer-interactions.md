# 第三方安装器交互采用分级处置

Status: accepted
Date: 2026-08-10
Related: ADR-0010, ADR-0035, ADR-0039

对受控安装档案明确列出、适用版本明确且运行时能可靠识别的第三方安装器条款、隐私或附加推广交互项，工作台优先自动处置；不能可靠自动处置时，依次退到工作台内明确确认和官方安装界面由用户处理。已知且可可靠处置的附加推广默认选择拒绝。登录、注册、验证码、付款和填写个人资料等账户与个人资料步骤一律直接交给官方安装界面中的用户，工作台不得代填、读取、传递或保存其内容。记录采用层级、预期选择、确认或回退事实，但不把记录表述为法律、隐私、来源或安装成功已经验证。

这保留用户希望的最大自动化程度，同时不把界面变化、未知目标或无法识别的输入伪装成自动处理。官方界面中的用户处理与“安装结果待确认”及运行时“手动应急处理”分别建模，之后仍必须通过受控安装档案定义的完成边界和结果检测。

用户取消、关闭或未完成账户与个人资料步骤时，当前软件项进入“安装器交互待处理”，只提供重新尝试或停止批次，不启动下一项。该状态跨工作台关闭和 Windows 重启保留；下次打开只显示原暂停项和两个命令，不自动打开官方安装界面或继续批次。该状态不表示安装失败、安装成功或安装结果待确认。
