# 以可直接读取的 TOML 维护软件目录

Status: accepted
Date: 2026-08-10
Related: ADR-0011, ADR-0027, ADR-0038

软件目录采用版本化 TOML 作为权威维护输入，工作台直接校验和读取；维护者只声明产品信息、来源用途与原始地址，工作台自动识别直链、跳转、普通网页、GitHub 或托管来源并产出类型化解析结果。调试模式可以提供图形化软件目录编辑器和手动导入，但它们只是同一版本化目录模型的维护入口：编辑意图和校验由应用核心处理，产出仍与 TOML 模式兼容，不能建立界面私有数据库、隐藏字段或第二事实来源。普通和高级视图不提供目录手动导入。编辑与“保存草稿”只更新目录编辑草稿；已经保存但尚未应用的草稿跨正常关闭和重新打开保留，仍标记为“已保存未应用”，直至维护者继续编辑、明确应用或删除，且删除草稿不改变当前有效目录、既有批次或历史。工作台在异常退出或电脑断电后尽量找回未保存的编辑内容，并把它明确标为“恢复的未保存修改”；该状态与已保存草稿和当前有效目录分离，不覆盖二者，也不自动保存或应用。恢复内容必须先由维护者明确保存才转为“已保存未应用”，放弃时只移除恢复部分；未能找回时不得伪报成功。只有用户明确点击“应用”，且当前已保存内容重新通过与文件加载相同的运行时校验后，才完整替换当前有效目录。整包错误使应用失败并保留旧目录与草稿；允许的局部依赖错误随整份新目录切换并禁用受影响项，不混用旧定义，因此不属于部分应用。运行时加载结果与正式发布门禁结果分别呈现且不能互相替代：运行时通过是正式发布通过的必要但不充分条件，运行时失败时发布结果只能失败或不可判定；`release_state = "draft"` 或其他仅发布级问题不阻止运行时通过的目录经图形化编辑器应用或调试模式手动导入后成为本机试用目录。该身份属于同一当前有效目录，不建立第三份目录。应用不改变维护目录发布状态或发布门禁结果，不能作为发布证据，也不改写既有批次快照；本机试用目录不得进入正式发行包。

该决定以消除 Markdown 人工转换和重复事实为优先，代价是必须长期维护目录模式、图形化编辑合同与项目内置受控解析能力；目录和编辑器均不得用脚本、选择器代码、任意命令或插件弥补未知网页，无法可靠解析时必须停止工作台自动处理。用户仍可按规格查看原始地址并在工作台外自行处理，但该交接不能补造解析结果、安装批次或工作台成功记录。调试模式的更高日志粒度也不改变这些边界。
