# 不以项目级信任证据阻断受控资源执行与更新

Status: accepted
Date: 2026-08-10
Related: ADR-0001, ADR-0005, ADR-0006, ADR-0010, ADR-0013

用户主动发起的一键更新，以及当前有效目录表达的第三方安装器取得和执行，不因项目缺少签名、摘要、发布者身份、来源真实性、许可、再分发结论或 provenance 而被项目级门槛阻断。项目可以保存原始与解析来源、冻结资源、启动、退出、结果检测和回退事实；未知仍应标为未知，记录不构成安全验证、来源认证或项目背书。

本决定不放开任意用户输入、目录脚本或可执行插件：所有操作仍通过当前有效目录、冻结批次和受控参数表达，手动交接文件不回灌到工作台，`SEC-08` 禁止内容继续排除。救援伴随工具仍遵循 ADR-0030 的受控制品边界。
