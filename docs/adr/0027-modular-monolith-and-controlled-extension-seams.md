# 采用同进程模块化单体与受控扩展接缝

Status: accepted
Date: 2026-08-10
Related: ADR-0019, ADR-0020, ADR-0038

初装工作台采用具有唯一装配入口的同进程模块化单体：WinUI 3 用户界面适配器、应用核心、可移植领域模块、Windows 适配器和基础设施适配器通过小型接口与单向依赖协作，每项业务状态只有一个可写所有者，外部效果通过生产适配器和无副作用测试适配器所在的真实接缝接入。普通软件、来源、驱动入口、系统设置和软件优化方案通过只包含受校验数据的目录内容扩展；全新的执行能力只能作为项目维护的内置模块加入并通过装配入口注册，不加载第三方代码插件。这一决定以单一进程的离线与恢复语义、深模块的可维护性、无用户界面测试能力和未来平台适配窗口为优先，代价是放弃独立部署的后端与第三方可执行插件生态；技术选择即使更新，也必须先满足接口简洁、状态清楚和长期维护要求。
