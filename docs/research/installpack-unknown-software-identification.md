# `installPack` 五个未知安装包识别记录

- 状态：研究结论
- 研究日期：2026-08-09
- 适用范围：`installPack` 候选目录中的五个 Windows 安装包
- 操作边界：只做官网核对、HTTP 元数据检查和本地 PE 静态读取；没有运行任何安装包

## 2. 研究方法与本地文件副作用

本次采用两类证据：

1. 官网、官方发布页、官方帮助或官方下载域名，用来确认产品身份和用途。
2. 本地样本的 PE 版本资源、证书表是否存在、可见证书主体字符串、文件大小和 SHA-256，用来确认该具体文件与官网产品是否相符。

五个文件原位于 Google Drive 云盘目录。对它们执行 `file`、SHA-256 和 PE 资源静态读取时，**触发了 Google Drive 将五个云盘占位文件取回到本机**。这改变了它们的本地占用状态，但没有执行安装包、加载其中代码或修改文件内容。本文中的“本地 PE 元数据”确实来自这些已取回的本地样本，不是第三方样本数据库。

本文没有：

- 启动安装程序或其内嵌程序；
- 验证安装后的实际行为、静默参数或卸载流程；
- 在 Windows 上验证 Authenticode 信任链是否有效；
- 下载当前官网完整安装包并与本地文件逐字节比较；
- 判断软件是否适合公开再分发或代替维护者作许可决定。

因此，“置信度”只描述**产品身份识别**，不等于安全认证、来源审计或实机验证。

## 3. 逐项结论

### 3.1 `Wand-12.40.0.exe`

**识别：Wand（原 WeMod）**

本地 PE 版本资源为：

- `ProductName=Wand`
- `ProductVersion=12.40.0`
- `CompanyName=WeMod`
- `LegalCopyright=Copyright © 2026 WeMod`
- 安装包内可见 `Wand-12.40.0-full.nupkg`、`WandAuxiliaryService.exe`、`WeMod.exe`
- PE 含 Authenticode 证书表，证书文本中可见 `WeMod LLC`；本次未验证证书链
- SHA-256：`675c313ff42d4d548dd85aae63648ce99d4c24ddaa9632842bbf9a123d7a7bee`

Wand 官方公告说明 WeMod 的目标原本是让用户修改单机游戏，并宣布产品更名为 Wand；原有模组、设置、Pro 状态和社区会继续保留。官网将其描述为为 PC 游戏提供 Gameplay Assists、游戏内指引、地图和难度或资源调整的工具。[W1][W2]

**置信度：高。** 文件名、版本资源、内嵌文件、证书主体和官方更名公告互相吻合。

**无法确认：** 官网没有在公开首页展示当前 Windows 安装包版本，因此只确认本地样本是 12.40.0，不能据此断言它仍是官网最新版。

**首版建议：** 在两种视图共同的“游戏工具”分类中展示，默认不勾选；显示名称使用“Wand（原 WeMod）”，避免老用户无法识别。它属于游戏辅助和模组工具，不应仅因功能类别被误标成 Crack 或 Keygen；但界面应提醒用户只对自己有权修改的游戏和模式使用。

### 3.2 `kedou_latest.exe`

**识别：Kedou 视频下载器**

Kedou 官网的下载器页面明确介绍 Windows 下载器具有断点续传、批量下载、视频嗅探、用户主页与播放列表解析等功能；官网前端脚本给出的 Windows 直链正是 `https://client.kedou.life/installer/kedou_latest.exe`。[K1][K2]

官网同时说明 Kedou 与“飞鱼视频下载助手”属于同一生态、信息互通。下载器页面还明确写明：外部应用视频嗅探需要安装 HTTPS 证书。这是产品能力说明，不是本文通过运行安装包推断的行为。[K1][K3]

本地 PE 版本资源为：

- `ProductName=kedou`
- `ProductVersion=2.1.4`
- `FileDescription=kedou Setup`
- `CompanyName=ACME`
- 外层 PE 没有 Authenticode 证书表
- SHA-256：`d755f62db86808d63e2de8fad8b1476116ca106abc77ae0af01f2171526c1139`

2026-08-09 查询官方同名直链时，服务器文件大小为 275,636,547 字节；本地样本为 275,585,169 字节。因此两者当时并非同一大小，不能把本地 `latest` 文件名理解为会自动保持最新。

**置信度：产品身份高。** 官网当前仍使用完全相同的文件名和官方子域名；本地产品名也吻合。

**无法确认：** 官网没有清楚披露可与安装包对应的公司法人名称；本地 `CompanyName=ACME` 是占位值，且外层安装程序没有 Authenticode 证书表。因此无法从现有证据确认具体发布主体，也没有对安装后证书行为进行实机验证。

**首版建议：** 在两种视图共同的“媒体下载”分类中展示，默认不勾选。普通下载能力和“外部应用嗅探／安装 HTTPS 证书”必须拆成不同说明；后者应由用户明确选择，不能随普通安装默认启用。离线包是否携带该样本应作为独立的发行清单决定，不由本次身份识别自动决定。

### 3.3 `setupbeta_jisu.exe`

**识别：360 安全卫士极速版**

360 官方社区的“360 安全卫士极速版”更新日志直接给出 `https://sfdl.360safe.com/setupbeta_jisu.exe` 作为最新版下载地址，官方版主的回复也重复给出该链接。[S1] 这比仅凭文件名猜测产品更可靠。

本地 PE 版本资源为：

- `ProductName=360 安全卫士`
- `FileDescription=360 安全卫士`
- `ProductVersion=15.0.3.1052`
- `LegalCopyright=(C)360.cn Inc.All Rights Reserved.`
- PE 含 Authenticode 证书表，证书文本中可见 `Beijing Qihu Technology Co., Ltd.`；本次未验证证书链
- SHA-256：`33eff100cb6cfb588f11d4846cf565e9e2c5ff1211c7d9175777d9aba2f730d5`

**置信度：高。** 官方产品版块、同名官方直链和本地 PE 产品资源完全一致。

**无法确认：** 本地样本比 2026-08-09 官方直链返回的文件小，未下载当前文件进行版本与哈希比较。文件名中的 `beta` 是厂商沿用的发布命名，不能单独证明这是一个应从首版排除的 Beta 产品。

**首版建议：** 修正原来的“产品不明／名称显示 beta”判断。在两种视图共同的“安全防护”分类中正常展示，默认不勾选；若用户同时选择火绒或其他常驻安全软件，应在入队前提示冲突并要求保留一个，不做自动叠装。

### 3.4 `sysdiag-all-x64-6.0.7.2-2025.07.29.1.exe`

**识别：火绒安全软件 6.0 x64 版**

本地 PE 版本资源为：

- `ProductName=火绒安全软件` / `Huorong Internet Security`
- `FileVersion=6.0.7.2`
- `CompanyName=北京火绒网络科技有限公司`
- 文件名明确包含 `all-x64`
- PE 含 Authenticode 证书表；本次未验证证书链
- SHA-256：`2578df51b1d04440725ad2707a95385b0ba8d14dac4347c0a729b4b07de310c0`

火绒官网的个人产品页介绍“火绒安全软件 6.0”，并分别提供推荐版、ARM 版、64 位版和 32 位版。官网 64 位下载入口在 2026-08-09 重定向到同样采用 `sysdiag-all-x64-版本-日期.exe` 命名的官方安装包。[H1][H2]

**置信度：高。** 产品名、公司名、版本、架构和官方 x64 文件命名全部一致。

**无法确认：** 本地 6.0.7.2 是历史版本；查询时官网 x64 入口已指向 6.0.11.2。本文未验证本地旧版本的安装结果或升级路径。

**首版建议：** 在两种视图共同的“安全防护”分类中展示，默认不勾选；在线安装使用官网当前稳定版，超大离线版可将维护者提供的固定版本明确标出。选择时与 360 安全卫士等常驻安全软件做互斥提示。

### 3.5 `uuyc_4.33.0.exe`

**识别：网易 UU 远程**

本地 PE 版本资源为：

- `ProductName=网易UU远程`
- `FileDescription=网易UU远程安装程序`
- `FileVersion=4.33.0.8907`
- `CompanyName=Netease`
- PE 含 Authenticode 证书表，证书文本中可见 `NetEase (Hangzhou) Network Co., Ltd`；本次未验证证书链
- SHA-256：`5e3cfe8cfdc6552c1fc26f1ad2c94df133ca20dc3c45c23155358c32ac9bf53e`

网易官方页面将 UU 远程描述为面向远程办公、远程游戏和远程协助的多端远程控制软件；官方下载页提供 Windows 客户端并展示当前版本。[U1][U2]

**置信度：高。** 文件名、产品资源、公司信息和网易官方产品页一致。

**无法确认：** 本地 4.33.0 已不是查询时官网展示的 4.35.0；本文没有测试安装后默认启动项、服务、被控权限或无人值守设置。

**首版建议：** 在两种视图共同的“远程控制”分类中展示，默认不勾选。安装前说明它是远程控制软件；安装完成后由官方安装程序或软件自身引导权限配置，工作台不应擅自替用户开启无人值守或常驻访问。
