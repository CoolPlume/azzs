# 安全政策

## 报告安全问题

请不要通过公开 GitHub Issue、Pull Request、Discussion 或提交记录披露安全漏洞、凭据、令牌、私钥、个人数据或其他敏感信息。

请在本仓库的 GitHub `Security` 页面使用“Report a vulnerability”提交私密漏洞报告。报告应尽量说明受影响的版本或提交、复现条件、影响范围和可用于验证的最小步骤；请勿附上真实凭据或不必要的个人信息。

## Security Policy

Do not disclose security vulnerabilities, credentials, tokens, private keys, personal data, or other sensitive information through public GitHub Issues, pull requests, discussions, or commits.

Use the private “Report a vulnerability” flow on this repository's GitHub `Security` page. Include the affected version or commit, reproduction conditions, impact, and minimal verification steps where possible. Do not include real credentials or unnecessary personal data.
