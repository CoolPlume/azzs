## 2. 已确认内容仍未落入目录

以下内容至少已经在候选审核稿或事项 19 中形成确认记录，但尚未成为启用的权威目录条目：

- 基础默认更新：Java 环境、.NET 环境、DirectX 兼容组件与检测修复、PowerShell 7。
- 普通常用锚点：微信、Steam、QQ 音乐；QQ 已存在。
- 超大离线版第二层：Chrome、360 压缩、WPS Office、PowerToys、图吧工具箱。
- 已完成静态识别：Wand、Kedou 视频下载器、360 安全卫士极速版、火绒安全软件、网易 UU 远程。
- 候选审核稿中其余已分类的软件、驱动与硬件工具仍需逐项判断是否属于“首版目录”“仅候选池”或“明确排除”。
- 两个维护者救援伴随工具尚无制品、稳定标识、版本、许可、架构、完整性或质量责任记录。

“审核稿已确认展示建议”不等于每个候选软件都已取得完整来源、安装档案、适用架构和再分发资格。正式同步必须逐条保留这个区别。

## 3. 现有模式不能完整表达的规则

| 已知规则 | 当前字段 | 缺口 |
| --- | --- | --- |
| 360 安全卫士极速版与火绒安全软件不能同时入队安装 | 只有 `dependencies` | 缺少冲突/互斥关系及冲突解决文案 |
| Kedou 的 HTTPS 证书能力必须单独选择 | 只有单个 `install_profile` 和 `optimization_note` | 尚未决定它是安装阶段选项还是安装后软件优化，不能先设计字段 |
| 三档内容版 | `bundled_editions` 目前只有 `large_offline` 示例 | 没有内容版注册表、救援版标识或制品矩阵权威位置 |
| 两个救援伴随工具 | 软件条目模式面向推荐软件来源 | 尚未决定它们是否属于目录内容、项目制品还是外部交接 |
| U 盘厂商网卡驱动 | 无驱动条目或交接模式 | “导入”尚未决定是外部交接还是工作台受控安装 |
| 硬件适用性 | 当前样例无硬件匹配字段 | 事项 19 要求驱动入口及硬件关联，但模式样例尚未表达 |
| 具体安装包架构与回退 | 运行时解析结果会产生架构 | 目录如何声明可接受分支/架构、离线资源如何固定架构仍不完整 |
| 离线随包资格 | `bundled_editions` 只是产品意图 | 缺少与再分发证据台账、版本/摘要和制品清单的引用 |
| 安装阶段受控能力 | `install_profile` 引用字符串 | 缺少档案注册表、适用版本范围、能力版本和未知引用的完整样例 |

前五项会受维护者决定影响，不能通过扩展 TOML 偷定语义。后四项可以先形成模式提案和有效/无效样例，再由发布门禁引用证据台账。

## 4. 内容、能力和证据必须分层

每个软件最终至少经过四个独立判断：

1. **目录资格**：是否作为软件安装项进入首版精选目录。
2. **运行资格**：来源能否解析，架构和版本是否明确，是否有匹配的受控安装档案。
3. **离线资格**：某个精确版本/架构的完整资源是否可离线安装。
4. **再分发资格**：项目是否有权把该精确二进制随公开制品或备用源分发。

只有第 1 项不能推出后面三项。联网官网来源可以满足目录资格但没有离线资格；本地安装包可以有离线价值但没有再分发资格；获得再分发许可也不能替代安装和结果验证。

## 5. 建议的填写批次

### 批次 A：先闭合模式和硬门禁

- 固定三档内容版的稳定标识与实际制品矩阵。
- 决定救援伴随工具和 U 盘驱动的责任边界。
- 决定冲突关系及 Kedou 证书能力归属。
- 补软件、驱动、受控安装档案、硬件适用性、离线资源与证据引用的模式提案。
- 为每个新字段提供最小有效、未知值、缺字段、重复标识、循环依赖和冲突选择样例。

### 批次 B：首版必达和基础锚点

- 保持 QQ、搜狗输入法稳定标识不变，补全搜狗受控安装档案与构建时支持基线。
- 加入 Java、.NET、DirectX、PowerShell 7，分别写清“缺少、旧版、已是最新版、无法确认”的检测与结果合同。
- 完成五个未启用占位的允许来源并启用，或明确修订事项 19 的首版承诺。

### 批次 C：已确认普通软件

- 加入微信、Steam、QQ 音乐和已确认的超大离线第二层内容。
- 加入 Wand、Kedou、360 安全卫士极速版、火绒安全软件和网易 UU 远程。
- 对候选审核稿其余条目逐项标记“首版”“后续”“排除”，不要把整张本地库存一次性转为精选目录。

### 批次 D：驱动、硬件与救援

- 仅在 Q2/Q3 决定后建立救援工具或外部交接记录。
- 厂商驱动入口必须有硬件适用信息；不匹配设备不因离线随包而执行。
- 驱动助手官网入口、厂商页面和本地资源分别建模，不能共用“可安装”布尔值。

## 6. 每批验收

- TOML 可解析，稳定标识唯一且不复用。
- 所有启用条目恰有一个 `primary` 来源，所有引用存在且无环。
- 来源用途、解析结果、安装档案和离线/再分发证据不存在重复事实字段。
- `release_state = "draft"` 时可做本机试用，但构建正式目录包必须失败。
- 所有首版必达项、具体适配基线和证据门禁闭合后，才讨论切换为 `release`。
- 标准视图与高级视图读取同一条目和选择状态，不按维护难度隐藏软件。
- 不含 Crack、Keygen、破解补丁、授权绕过内容或链接。
