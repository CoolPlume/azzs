# 第十二轮 Grill 答案登记

Status: resolved  
Date: 2026-08-10  
Scope: 显示缩放、多显示器、图形适配器与多核性能边界

## 已确认决定

- 4K、Windows 225% 显示缩放是首版必达的适配与验收场景。界面还必须分别适配 Windows 显示缩放与文本缩放，避免文字、命令、状态、列表、对话框和进度在不同分辨率或缩放下过大、过小、截断、重叠或不可操作。
- 工作台支持分辨率、DPI 和显示缩放不同的多显示器。窗口跨屏、显示器接入、断开或主显示器改变后重新布局而不重启；当前页面、核心状态、选择、焦点、滚动语义、未提交输入和批次显示保持，原窗口位置不可见时回到可用工作区。
- 集成显卡、独立显卡和混合图形设备都必须正常运行。工作台遵从 Windows 的图形适配器选择，不提供手动 GPU 选择器；材质和动效等视觉增强允许降级为实体背景和静态反馈，但功能、状态、可读性、无障碍和输入路径不降级。
- 适合的无系统修改、彼此独立且可合并结果的 CPU 密集型内部计算可以在受限上限内使用多核；调度必须可取消、保留界面响应并由核心统一拥有。软件安装、系统优化、软件优化、批次状态提交、结果确认和恢复判断仍串行互斥，不能借多核并行执行管理员操作。

## 验证记录边界

4K、225% 显示缩放、多显示器、图形适配器和受限多核均须写入规格与开发者发布证据的验收范围。真实设备证据未取得时，按 `REL-08` 记录“未实机验证”，不阻止既定发布门槛，也不得把自动检查或文档合同表述为实机通过。
