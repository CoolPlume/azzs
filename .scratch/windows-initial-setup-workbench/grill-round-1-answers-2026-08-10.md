# Grill 第一轮答案登记

Status: resolved  
Date: 2026-08-10

本文件只记录维护者对第一轮建议的简写回答，不替代正式规格或 ADR；`n` 代表拒绝推荐方向，但在替代方案明确前不生成产品门槛。

## 已确认

- Q1：恢复的未保存修改在启动时只显示不阻断的持续“继续编辑”入口，用户主动进入编辑器，不自动打开。
- Q2：救援伴随工具只有成为项目受控制品并通过相应发行检查后才能随包和启动，否则外部交接。
- Q3：U 盘厂商网卡驱动只走外部交接，工作台不选择或安装具体 INF/EXE。
- Q4：不以签名、摘要、发布者、来源真实性或信任链作为用户主动一键更新、当前有效目录内第三方安装器取得或执行的项目级门槛；仍如实记录原始与解析来源、冻结资源、执行和结果事实，缺失即为未知，不得写成安全已验证或项目背书。
- Q5a-l：接受完整推荐包。状态主体、`ProgramData` 权威状态、N/N-1、同机缓存、10 秒检查点、设备与用户范围、权威提交与上一可信代次、写时复制、检查点冲突、日志退化、卸载与清理边界及证据范围以 ADR-0029 为准。
- Q6：软件当前状态与具体安装操作结果分层。
- Q8：真实 Windows 或目标软件实机验证不阻断公开发行，但开发者发布证据必须如实记录“未实机验证”，用户文案不得暗示已经验证。
- Q10：完全不提供摘要、源码关联或 provenance；继续保持未签名发行口径。
- Q11a-b：ARM64 命名资产的关键安装链原生 ARM64；标准 Repair 只恢复安装器拥有的程序文件和声明资源。
- Q12：接受“书面确认 WiX 7 官方条款适用性；不接受且不自建则淘汰”的决策过程，不代表已经接受 EULA。
- Q13：普通卸载只删除程序资产和登记，默认保留 `ProgramData` 数据；删除本机数据另作受保护操作。
- Q14：首版锁定版本和输入，在固定构建器上解释两次输出差异；不默认承诺跨构建器 bit-for-bit。
- Q15：ARM64 首装使用原生资产；既有 x64 安装版采用保留共享状态的受控互斥迁移。
- Q9：当前及以后正式列入候选的资源均可随包和公开发布，不以 `accepted`、许可证据、来源身份或再分发结论作为项目内容准入门槛；这不是对任何资源已经安全验证、身份闭合或取得第三方权利的事实断言。
- QA：首版目录范围包含 QQ、搜狗输入法、Game Cheats Manager、Cheat Engine、Office Tool Plus、Internet Download Manager、几何画板、Java、.NET、DirectX 和 PowerShell 7。精确来源、资产和安装档案仍按目录结构补齐，不凭空填写。

本轮未开始产品代码、构建或发行；Q7 与 Q16-Q19 的后续结论已记录在[第二轮答案登记](grill-round-2-answers-2026-08-10.md)，不再把本轮末尾的原前沿视为未决事项。
