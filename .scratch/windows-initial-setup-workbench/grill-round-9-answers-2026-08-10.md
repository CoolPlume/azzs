# 第九轮 Grill 答案登记

Status: resolved  
Date: 2026-08-10  
Scope: 更新故障恢复界面的完成条件、信息和操作边界

## 已确认决定

- Q39：选择方案 1。只有用户能正常使用工作台且原有记录仍可见，才算恢复成功。
- Q40：选择方案 1。恢复界面列出各次失败的版本、时间和当前未恢复状态，并提供手动下载与诊断资料。
- Q41：选择方案 2。恢复界面允许只读查看历史和日志；初始化操作、设置修改和清理不可用。
- Q42：选择方案 1。优先提供当前匹配的正式稳定制品，同时保留浏览全部 GitHub Release 的入口。
- Q43：选择方案 1。无网络时仍显示可复制下载地址、故障摘要和诊断导出，供稍后或在另一台设备处理。
- Q44：选择方案 1。进入双版本故障恢复后，不提供再次启动已失败版本的命令。

## 同步边界

- 恢复界面以静态错误状态呈现，不自动跳转或使用完成动效。
- 打开链接、下载、导出资料和用户自行声明都不结束恢复状态；只有可正常使用且保留原有记录的工作台实际出现后才结束。
