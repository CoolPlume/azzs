# 实现系统优化应用与验证

Type: task  
Status: ready-for-agent  
Blocked by: 02, 04, 24

## Goal

安全执行精选目录中的系统优化单项或推荐总体优化，记录原值并验证结果。

## Acceptance Criteria

- [ ] 只执行当前有效系统设置目录中的受控设置项，不接受用户输入的脚本、命令、注册表内容或目标路径。
- [ ] “推荐总体优化”只是同一批设置项的可调整组合；无论从总体方案还是单项入口执行，都共享同一状态、历史、验证与撤销语义。
- [ ] 总体方案在执行前显示摘要并允许展开、勾选或取消各设置；低影响项目可以默认选择，明显改变使用习惯或界面且影响较大的项目默认不选。
- [ ] 不按当前用户、软件账号或整台电脑给设置分类或决定是否收录，只用通俗文案说明实际会影响什么。
- [ ] 执行前展示目标效果、当前状态、说明来源、已知适用版本、资源管理器或 Windows 重启要求和撤销能力。
- [ ] 已符合目标状态的项目显示“已生效”并跳过重复修改。
- [ ] 执行前保存可逆设置原值，并按依赖关系确定执行顺序。
- [ ] 执行时冻结设置稳定标识、目录版本、目标、验证、撤销和重启语义。
- [ ] 执行后验证工作台发起的变更并显示成功、失败或等待重启。
- [ ] 单项失败不终止没有依赖关系的后续设置，结果按实际设置逐项显示，不以总体方案名称掩盖部分失败。
- [ ] 对超出目录已知适用 Windows 范围的设置，标准视图显示“可能不适用”并禁用普通执行；高级视图仅在具备恢复方案时提供“仍然尝试”，单独说明风险并记录确认。
- [ ] 支持目录预定义的“Windows 11 经典右键菜单”和“Windows 10 风格资源管理器”设置直接应用或恢复 Windows 11 默认状态；每次修改前均保存当时状态和恢复数据。
- [ ] 上述两项生效需要重启资源管理器时，提供“立即重启资源管理器”和“稍后处理”；立即重启前说明任务栏与已打开的资源管理器窗口会短暂关闭，稍后处理则保存“等待资源管理器重启”状态。
- [ ] 资源管理器或 Windows 后续重启、以及工作台重新打开后会重新检测上述两项的实际状态，未验证前不宣称已经生效。
