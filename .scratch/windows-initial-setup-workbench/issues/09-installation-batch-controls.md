# 实现批次停止、强制终止与重试

Type: task  
Status: ready-for-agent  
Blocked by: 08

## Goal

提供含义明确的正常停止和高风险强制终止，并保留已完成结果与重试能力。

## Acceptance Criteria

- [ ] 正常停止允许当前安装程序结束，并阻止后续项目启动。
- [ ] 下载阶段停止会取消当前下载、删除临时文件并停止后续项目。
- [ ] 下载阶段可暂停和继续当前项目，暂停时保留进度且不与停止批次混淆；无法续传时明确提示重新下载。
- [ ] 强制终止按钮明确说明半安装状态风险并要求确认。
- [ ] 两种停止方式都不回滚已完成安装。
- [ ] 关闭工作台不再启动后续项目，也不被误当作强制终止已启动的外部安装程序。
- [ ] 关闭工作台会停止未完成或已暂停的应用内下载并清理临时文件，重新打开后等待用户明确重新开始。
- [ ] 重新打开后先验证外部安装程序的结果，再允许用户继续或重试。
- [ ] 批次保留逐项结果，失败或未完成项目可单独重试。
- [ ] 停止、强制终止和用户确认均写入执行日志。
- [ ] 安装批次活动期间不能开始优化批次，并提供返回当前安装进度的入口。
