# 完成应用设置页面

Type: task  
Status: ready-for-agent  
Blocked by: 03, 04, 05, 07, 11, 15, 17, 24, 25

## Goal

集中提供应用、目录、缓存、架构、日志和恢复记录的用户可控设置。

## Acceptance Criteria

- [ ] 提供仅显示正式稳定发行的应用主动更新入口；当前运行测试发行时提供用户主动的“切换到最新稳定版”，缺少匹配制品时明确显示不能自动更新并提供手动下载入口。活动或待恢复初始化操作存在时显示更新已延后、原因和返回当前任务入口，不下载、替换或中断任务。
- [ ] 软件与驱动目录、系统设置目录和软件优化目录分别提供更新和回退入口；三类目录的手动导入只在调试工具区提供。
- [ ] 提供 ARM64 软件包架构偏好。
- [ ] 提供缓存期限、位置和手动清理操作。
- [ ] 提供日志导出、立即清空，以及恢复记录查看和主动删除。
- [ ] 提供默认关闭且即时生效的调试模式开关，跨应用重启保留选择；启用状态清楚可见，并提供日志位置、单个自包含诊断文件导出、图形化软件目录编辑器和三类目录手动导入入口。导出前显示覆盖时间、文件大小、已执行脱敏和已知采集缺口，导出不触发上传。
- [ ] 提供标准视图与高级视图即时切换，无需重启应用，切换后保留当前状态。
- [ ] 首次运行默认使用标准视图，并按状态主体隔离、跨应用重启保存用户选择的视图；当前用户默认不读取其他状态主体的偏好或草稿检查点。
- [ ] 高级视图增加低频设置与详细控制，但不提供任意命令或绕过风险规则。
- [ ] 调试模式独立于标准视图与高级视图，不因切换视图改变启用状态；关闭调试模式只隐藏调试工具并恢复普通日志粒度，不静默删除日志、目录数据或业务状态。若目录编辑器存在未保存修改，关闭调试模式和切换视图都不弹出关闭工作台时的三项确认，也不自动保存、放弃或应用；同一次运行中重新打开编辑器后仍显示“未保存更改”。关闭调试模式后若用户真正关闭工作台并选择“返回编辑”或保存失败，可以临时恢复原编辑会话，但调试模式偏好和普通日志粒度保持不变，再次离开后入口继续隐藏。
- [ ] 异常退出或电脑断电后，下次启动尽量找回的目录修改在任何设置或编辑入口中都明确标为“恢复的未保存修改”，不得显示为已保存、已应用或恢复成功后的完成状态；它与已保存未应用草稿和当前有效目录保持独立，应用继续不可用，直至用户显式保存。保存成功后转为“已保存未应用”并清除对应恢复状态；放弃恢复内容不删除此前草稿、不改变当前目录、既有批次或历史。找回失败不得显示已找回；启动时只显示不阻断的持续“继续编辑”入口，不自动打开编辑器。
- [ ] 关闭调试模式不撤销或隐藏已经生效的本机试用目录身份；重新启动后按已保存的调试模式状态决定编辑器和导入入口是否显示，无论入口是否显示，设置页的软件与驱动目录当前状态、软件安装页和推荐流程软件阶段都继续显示未发布状态。
- [ ] 调试模式手动导入的软件目录存在运行时整包错误或未知执行语义时拒绝加载；运行时可加载但正式发布门禁未通过时，用户确认后成为本机试用目录，并在设置页的软件与驱动目录当前状态原位立即显示与图形化编辑器应用相同的持续提示、日志和新批次标记；焦点返回并留在触发导入的命令，屏幕阅读器只礼貌播报一次。
- [ ] 危险或不可逆操作说明影响并要求确认。
- [ ] 受待恢复状态约束的操作正确禁用并显示原因。
