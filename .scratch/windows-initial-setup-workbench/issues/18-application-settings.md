# 完成应用设置页面

Type: task  
Status: ready-for-agent  
Blocked by: 03, 04, 05, 07, 11, 15, 17, 24, 25

## Goal

集中提供应用、目录、缓存、架构、日志和恢复记录的用户可控设置。

## Acceptance Criteria

- [ ] 提供应用主动更新入口。
- [ ] 软件与驱动目录、系统设置目录和软件优化目录分别提供更新、导入和回退入口。
- [ ] 提供 ARM64 软件包架构偏好。
- [ ] 提供缓存期限、位置和手动清理操作。
- [ ] 提供日志导出、立即清空，以及恢复记录查看和主动删除。
- [ ] 提供标准视图与高级视图即时切换，无需重启应用，切换后保留当前状态。
- [ ] 首次运行默认使用标准视图，并跨应用重启保存用户选择的视图。
- [ ] 高级视图增加低频设置与详细控制，但不提供任意命令或绕过风险规则。
- [ ] 危险或不可逆操作说明影响并要求确认。
- [ ] 受待恢复状态约束的操作正确禁用并显示原因。
