# 实现驱动获取页面

Type: task  
Status: ready-for-agent  
Blocked by: 03, 07, 08, 12, 13, 24

## Goal

依据硬件概览组织驱动助手和官方厂商页面，同时保持工作台不直接管理具体驱动包的边界。

## Acceptance Criteria

- [ ] 显示精选驱动助手入口和固定厂商/OEM 页面入口。
- [ ] 硬件识别成功时推荐或高亮相关入口，失败时固定入口仍可用。
- [ ] 助手未安装时提供安装，已安装时提供启动。
- [ ] 工作台不直接匹配、下载或安装具体驱动包。
- [ ] 启动外部驱动操作前保留流程进度并标记“驱动交接中”。
- [ ] 外部操作返回或下次启动时由用户选择“已完成”“需要重启”或“暂时跳过”，不自动判定完成。
- [ ] 能处理网络、显示和硬件识别变化；用户选择需要重启时建立重启屏障。
