# 实现推荐初始化流程

Type: task  
Status: ready-for-agent  
Blocked by: 08, 10, 12, 14, 15, 24, 26

## Goal

在概览页提供“驱动 → 系统优化 → 软件安装 → 软件优化”的非强制一条龙流程与结果总结。

## Acceptance Criteria

- [ ] 启动默认进入概览，并按确认顺序显示四个阶段。
- [ ] 系统优化阶段显示“推荐总体优化”的摘要，可展开并调整其中引用的同一组设置项；从总体方案或单项入口修改的选择和状态始终一致。
- [ ] 系统优化阶段可预选低影响项目，明显改变界面或使用习惯且影响较大的项目保持未选；经典右键菜单与 Windows 10 风格资源管理器首版默认不选。
- [ ] 没有可优化软件或适用方案时自动跳过软件优化阶段，独立软件优化页仍可进入。
- [ ] 软件优化阶段预选所有适用软件中的低影响推荐项，高影响项保持未选，用户明确提交前不创建或执行优化批次。
- [ ] 各一级页面始终可独立使用，不被流程锁定。
- [ ] 驱动阶段可标记为“已完成”或“暂时跳过”。
- [ ] 每次推荐流程使用独立流程记录，不和系统优化执行记录、软件安装批次或软件优化批次混为一体。
- [ ] 重启屏障暂停后续阶段，提供立即或稍后重启，并可在恢复后继续。
- [ ] 完成或暂停时汇总已完成、部分完成、失败、跳过、无适用项、未执行、结果待确认、等待资源管理器重启、等待重启和紧急撤回项目。
- [ ] 总结只为当前仍可执行的失败项提供重试，并提供日志查看入口。
- [ ] 普通用户可理解当前阶段、下一步和暂停原因。
