## Goal

在概览页提供“驱动 → 系统优化 → 软件安装 → 软件优化”的非强制一条龙流程与结果总结。

## Acceptance Criteria

- [x] 启动默认进入概览，并按确认顺序显示四个阶段。
- [x] 系统优化阶段显示“推荐总体优化”的摘要，可展开并调整其中引用的同一组设置项；从总体方案或单项入口修改的选择和状态始终一致。
- [x] 系统优化阶段可预选低影响项目，明显改变界面或使用习惯且影响较大的项目保持未选；经典右键菜单与 Windows 10 风格资源管理器首版默认不选。
- [x] 没有可优化软件或适用方案时自动跳过软件优化阶段，独立软件优化页仍可进入。
- [x] 软件优化阶段预选所有适用软件中的低影响推荐项，高影响项保持未选，用户明确提交前不创建或执行优化批次。
- [x] 各一级页面始终可独立使用，不被流程锁定。
- [x] 驱动阶段可标记为“已完成”或“暂时跳过”。
- [x] 每次推荐流程使用独立流程记录，不和系统优化执行记录、软件安装批次或软件优化批次混为一体。
- [x] 重启屏障暂停后续阶段，提供立即或稍后重启，并可在恢复后继续。
- [x] 推荐流程中的软件来源无法自动解析时，可进入来源手动交接；流程记录保留软件稳定标识、原解析失败原因、打开的原始地址、交接时间，以及每次重新检测的时间和结果，不创建安装批次或虚构工作台下载安装记录。
- [x] 重新检测为“外部安装已识别”后，该软件满足只要求存在的依赖并可进入软件优化发现；需要实际版本时仍单独检测，流程总结继续保留外部安装标记。
- [x] 来源手动交接跨工作台关闭和 Windows 重启保留；它本身不建立重启屏障或触发自动打开，用户下次主动打开后恢复当前流程位置和“重新检测”，且不静默继续后续阶段。
- [x] 重新检测成功后仍停留在当前软件阶段并显示“继续”；只有用户点击后才按当前目录、设备状态、依赖和剩余选择重新判断后续内容，关闭或重启后也恢复到同一续接点。
- [x] 重新检测仍未发现目标软件时不允许用户强制标记成功，只提供“重新检测”和“暂时跳过”；暂时跳过不满足依赖、不进入软件优化发现或产生安装成功记录，依赖项保持阻塞，无依赖的其他项目可以继续。
- [x] 暂时跳过的软件仍列入未完成列表并保留“重新检测”，不会因推荐流程继续、显示总结、关闭或重启而消失；以后识别成功才移出未完成状态，交接历史仍保留。
- [x] 外部安装识别成功并由用户点击“继续”后才重新规划依赖；当前已满足依赖的软件恢复为可选择状态并保持未勾选，仍缺其他依赖的软件继续显示阻塞原因，且不自动创建批次、下载或安装。
- [x] 当前有效软件目录属于本机试用目录时，推荐流程的软件阶段在标准视图与高级视图持续显示不可关闭的静态文字状态，说明它尚未通过正式发布检查且只影响之后的新任务；关闭调试模式、视图切换和重新启动不隐藏该身份或重复无障碍播报，也不播放完成或庆祝动效。
- [x] 完成或暂停时汇总已完成、外部安装已识别、部分完成、失败、暂时跳过、无适用项、未执行、结果待确认、等待资源管理器重启、等待重启和紧急撤回项目。
- [x] 总结只为当前仍可执行的失败项提供重试，并提供日志查看入口。
- [x] 普通用户可理解当前阶段、下一步和暂停原因。
