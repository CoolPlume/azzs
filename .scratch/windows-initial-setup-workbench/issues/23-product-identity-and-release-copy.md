# 补充产品标识与发布文案

Type: task  
Status: needs-info  
Blocked by: 01

## Goal

根据维护者后续提供的选择，补齐公开发布所需的正式产品标识与中文文案。

## Information Needed

- 产品正式名称。
- 应用图标及其使用范围。
- GitHub 仓库与 Releases 的产品简介。
- 未签名、无校验值和 SmartScreen 风险说明文案。
- 最低目标版本及旧版本继续运行风险说明文案。

## Acceptance Criteria

- [ ] 应用、安装程序、便携包和离线资源版使用一致的正式名称与图标。
- [ ] GitHub 发布说明能区分版本、发行形态和 x64/ARM64 架构。
- [ ] 风险说明准确披露未签名和无项目校验信息，不暗示已验证第三方包。
- [ ] 首版文案为简体中文，并可纳入后续语言扩展。
