# 延期真实 Windows 软件安装验证

Type: task  
Status: ready-for-human  
Resolution: open
Blocked by: 38
Owner: issue-39
Consumers: none
Verification: 在真实 Windows 11 x64 候选设备上，按正式目录每种来源解析/取得机制和受控安装档案运行代表性真实第三方软件安装，并保留可追溯的前后状态与结果检测证据。
Evidence freshness: 绑定候选设备、Windows build、软件安装器版本、目录修订、受控安装档案、生产适配器和精确应用提交；任一输入改变后重跑受影响路径。

## Goal

在不把 mock、构建结果或安装器退出码误写为实机成功的前提下，为正式目录的生产安装能力取得真实 Windows 11 x64 代表性闭环证据。

## Boundary

`v0.1.0` 明确不在本机、虚拟机或其他候选设备安装第三方软件，因此本事项不阻止本版本 Beta 发布，也不会因 Beta 发行而自动完成。它只在后续获得真实候选设备与明确安装授权后启动。

## Acceptance Criteria

- [ ] 每类真实来源解析/取得机制和受控安装档案至少有一条代表性 Windows 11 x64 闭环，覆盖来源解析、网络状态、存在检测、取得、启动、交互、安装后置行为与结果检测。
- [ ] 记录安装前后稳定事实、实际安装器版本/架构、受控交互、返回结果和检测依据；不能可靠判断时记录“安装结果待确认”，不写成功。
- [ ] 明确列出未执行的软件、版本、重启、设备、ARM64 与安装生命周期，且不把代表性路径外推为全部软件实机通过。
