# 实现应用主动更新与失败回退

Type: task  
Status: ready-for-agent  
Blocked by: 01, 02

## Goal

提供用户主动控制的 GitHub 应用更新，并在任何更新阶段失败时保留可用旧版本和设备状态。

## Acceptance Criteria

- [ ] 支持从 GitHub 手动下载和工作台内一键更新。
- [ ] 不后台静默下载、不强制替换应用。
- [ ] 更新前披露发行包未签名且项目不提供完整性校验信息。
- [ ] 下载、替换或新版启动失败时自动恢复上一版本。
- [ ] 更新和回退不改变恢复记录、执行历史、待恢复流程或有效紧急撤回信息。
- [ ] 更新结果和失败原因写入详细本机日志。
