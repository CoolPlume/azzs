## Confirmed Content

- QQ 是待归类的软件安装项，其 Windows 官网发布页为 `https://im.qq.com/index/#/windows`。
- QQ 使用面向普通个人用户的官方 Windows 发行分支，不与企业版、国际版或其他产品分支混用版本号。
- QQ 的“安装最新版”从官网当前发布数据取得稳定版及对应架构的官方安装文件，不长期写死某一版本的 `.exe` 地址。
- 其他具有官网发布页的软件采用相同原则；维护者只保留稳定原始地址，每个站点的具体获取规则由项目内置受控解析能力维护，不进入目录数据。
- 搜狗输入法是首版已确认的软件安装项，其 Windows 官网发布页为 `https://shurufa.sogou.com/windows`，最新版按与 QQ 相同的官网解析原则取得。
- 搜狗输入法的安装阶段提供两个明确选项：自定义安装时取消“开启搜索候选，让输入和信息获取更简单”，以及安装完成时不安装“腾讯元宝”。
- 上述两个安装阶段选项与安装后的搜狗输入法软件优化分开维护，均属于首版必达项；它们属于已知可靠的附加推广拒绝偏好。目录声明支持且运行时仍可可靠识别的搜狗安装器优先由工作台自动处置，自动处置失败时依次退到工作台确认和官方安装界面，不把回退写成自动完成或手动应急处理。
- 首版内置目录必须记录并支持构建目录时从搜狗官网解析到的当前稳定安装器基线；官网以后发布的新安装器继续按最新版规则下载，但在目录尚未适配时不得伪称受支持。
- Game Cheats Manager、Cheat Engine、Office Tool Plus、Internet Download Manager 和几何画板进入首版普通软件清单，默认不勾选，并分别提供与安全软件或反作弊影响、联网游戏或账号影响、商业许可责任和候选资源未经项目验证有关的必要提示。
- 上述五个软件在标准视图与高级视图中使用同一目录项和选择状态；明确属于破解或授权绕过的资源仍排除，但合法软件可以改用其他允许来源。
- 上述五个软件可以随超大离线版携带安装资源，也可以配置项目 GitHub 备用包；是否在具体制品中包含由目录与制品构建清单决定，不以 `accepted`、许可证据、来源身份或再分发结论作为项目准入门槛。
- Java、.NET、DirectX 和 PowerShell 7 均纳入首版目录范围；当前只保留未启用草案条目，精确发行版、来源、架构、离线安排和安装档案待补齐。

## Acceptance Criteria

- [ ] 每个目录项拥有唯一且不可复用的稳定标识。
- [ ] 软件目录维护文件中的每个启用条目都由工作台直接校验和读取；每个原始地址均能由唯一来源解析能力产出完整结果，无法处理时使用准确状态而不要求维护者改填最终直链。
- [ ] 每个软件的分类、依赖、发行分支、来源用途、解析方式、版本、架构、离线状态和静默安装支持情况完整；前述解析事实不得与维护者字段重复维护。
- [ ] 存在安装阶段选项的软件声明每个选项的效果、默认选择及受控处理能力；首版必达项缺少执行规则时阻止发布，已有规则运行失败时具有准确的手动应急提示。
- [ ] 支持从官网发布页取得当前稳定版的软件均记录稳定官网入口及相应获取规则，不把易变化的安装文件直链当作永久最新版。
- [ ] 搜狗输入法目录项包含已确认的官方来源和两个安装阶段选项，至少为首版内置目录构建时的当前稳定安装器基线提供自动处理规则；仅有手动提示或没有任何受支持基线不能满足首版目录要求。
- [ ] 五个需要额外提示的普通软件均具有稳定标识、默认未选状态和对应的简短提示，并能在安装批次确认摘要中重复本次相关提示。
- [ ] 两种视图显示相同的五个软件安装项、分类、可选择状态和勾选结果；目录不包含任何明确的破解或授权绕过资源及链接。
- [ ] 五个需要额外提示的普通软件可按目录和制品构建清单标记为本机内置或项目 GitHub 备用包；未被当前制品携带且无缓存时，联网安装和断网等待状态符合目录声明。
- [ ] `catalog/software-catalog.toml` 中十一项首版范围的软件均有对应条目；未启用条目在补齐其结构字段、来源与受控安装档案后改为 `enabled = true`，不得凭空填写技术事实。
- [ ] 目录在存在未启用的首版范围条目或其他结构性发布门禁未通过时保持 `release_state = "draft"`；只有全部首版必达软件、依赖、来源和受控安装档案通过发布级校验后才能改为 `release`。来源、许可、身份和再分发研究继续记录事实，但不作为候选资源随包或公开发布的项目准入门槛。
- [ ] 每个驱动入口指向明确官方厂商资源并具备适用信息。
- [ ] 所有内容通过目录模式、身份和依赖规则校验。
- [ ] 至少一组软件和驱动入口可用于首版端到端验收。
