# 实现软件与驱动目录生命周期

Type: task  
Status: ready-for-agent  
Blocked by: 01, 02

## Goal

加载、更新、导入和回退软件与驱动目录，并在整体错误与局部错误之间采用不同处理。

## Acceptance Criteria

- [ ] 内置目录可离线加载，目录项使用不可变稳定标识。
- [ ] 官网软件目录项明确记录软件发行分支，最新版解析不会跨个人版、企业版或国际版等分支比较版本。
- [ ] 软件目录项可声明交互式或静默安装能力；静默安装方式、条款/隐私/附加推广交互项的自动处置、工作台确认与官方界面回退层级、完成边界、安装后置行为、重启后验证和结果检测规则均属于受控目录数据，不接受用户输入任意命令。账户与个人资料步骤不进入自动处置或工作台确认，始终由用户在官方安装界面完成；已知且可可靠处理的附加推广默认拒绝。
- [ ] 存在安装阶段偏好或安装器交互项时，目录项声明偏好与处置定义、支持的安装器版本、受控执行器引用、完成边界、安装后置行为、重启后验证和结果验证规则；缺少任一必需字段时阻止该项执行，首版必达偏好缺失时阻止发布。
- [ ] 来源解析结果明确区分可下载文件来源与托管安装来源；维护者填写的 TOML 不声明地址技术类型，解析结果缺少批次所需事实时阻止该项执行。
- [ ] 软件目录维护文件只要求来源用途和一个 HTTP(S) 原始地址；工作台自动识别直链、跳转、普通网页、GitHub 和已支持托管来源，目录本身不能携带解析脚本或任意代码。
- [ ] 工作台直接进行 TOML 模式校验和读取；维护者不需要修改 C++，也不存在开发者手工抄写产品字段的第二份目录数据，未完成条目以 `enabled = false` 保留且不展示或执行。
- [ ] 调试模式的图形化软件目录编辑器使用与 TOML 加载相同的领域模型和核心校验，可维护模式支持的分类、软件、依赖、来源、版本、发行安排、说明和本地化字段；编辑与“保存草稿”只更新目录编辑草稿，“应用”重新校验当前已保存内容并复用同一运行时目录加载与原子替换路径，界面不建立第二份目录格式。
- [ ] TOML 按稳定软件标识声明依赖；存在安装阶段偏好时通过 `install_profile` 关联唯一受控安装档案，不在软件条目、界面和执行器中重复偏好与验证事实。软件选择遇到未选必需依赖时，使用同一依赖闭包一次列出全部新增项并等待用户确认，不由目录加载或执行器静默补选。
- [ ] 维护文件先校验 `enabled = false` 未启用条目的最小结构、再校验启用条目完整结构；运行时加载结果与正式发布门禁结果分别计算，但运行时通过是正式发布通过的必要条件，运行时失败时发布结果不能通过。`release_state = "draft"` 的内容通过运行时校验后可在调试模式应用或从调试工具区导入为本机试用目录，但发布目录必须为 `release` 且所有首版必达条目均已启用并通过能力校验。
- [ ] 软件和分类稳定标识不随显示语言改变；新增翻译只增加本地化文字，不能复制或改写来源、版本、依赖和安装行为。
- [ ] 软件目录项可以声明简短的必要提示；需要提示的普通软件在两种视图中使用同一目录项并默认不勾选，提示内容随目录项更新，不由界面另存一份。
- [ ] 排除某个资源不自动排除可使用其他允许来源的合法软件安装项。
- [ ] 支持主动更新、调试模式手动导入、降级预览和上一可用版本回退；普通和高级视图没有导入入口。
- [ ] 调试模式手动导入显示候选文件路径、目录版本和项目数量，并在用户确认后记录加载、拒绝或应用结果；目录校验和执行边界不因导入而变化。
- [ ] 调试模式手动导入的软件目录存在运行时整包错误或未知执行语义时拒绝加载；运行时可加载但正式发布门禁未通过时，确认后使用与图形化编辑器相同的本机试用目录身份、持续提示、日志和新批次标记，不能通过导入绕过未发布状态。
- [ ] 未知展示或说明字段可忽略；未知模式版本或会改变目标、来源、依赖、受控能力、执行、检测、恢复、重启、撤回或其他操作语义的内容，连同缺少必需字段、无法解析或稳定标识冲突，都拒绝整包并保留当前有效目录。
- [ ] 不存在或循环依赖只禁用受影响项，并在页面和日志中说明原因。
- [ ] 目录配置错误项没有强制安装入口，修复后不自动改写旧批次。
- [ ] 整包级运行时错误使应用失败并保留原当前有效目录、目录编辑草稿和可定位错误；`CAT-13` 至 `CAT-17` 允许的局部依赖错误不阻止整份新目录切换，受影响项按新目录禁用且不沿用旧定义，这不属于部分应用。成功应用只影响之后的软件列表、规划和新建批次，不取消、重排、补项或改写既有批次及历史。“保存草稿”成功时该版本即持久化；正常关闭、异常退出或电脑断电后重新打开，恢复该已保存版本为“已保存未应用”，直至继续编辑、明确应用或删除，且任何恢复都不会自动应用；删除草稿不改变当前有效目录或既有记录。同一次运行中存在未保存修改时，切换页面、切换标准视图与高级视图或关闭调试模式不弹关闭确认，修改继续保留且不自动保存、放弃或应用，重新打开编辑器仍显示“未保存更改”。只有主动关闭整个工作台时才让用户保存草稿并关闭、仅放弃未保存部分或返回编辑，保存失败不能关闭，三条路径均不能应用目录。本机试用身份属于同一当前有效目录，本机应用不改变 `release_state` 或正式发布门禁结果，关闭调试模式不撤销该目录或隐藏其未发布身份。
- [ ] 当前有效软件目录替换影响尚未创建批次的已有选择时，目录核心只报告受影响项及原因；软件选择用例保留选择并要求用户显式处理，不得把旧目录定义冻结进未创建批次的选择。
- [ ] 异常退出或电脑断电后，下次启动应尽量找回目录编辑器尚未保存的修改，并明确标为“恢复的未保存修改”；它仍是未保存状态，绝不自动保存或应用。目录核心分别建模恢复的未保存修改、已保存未应用草稿和当前有效目录，找回不得覆盖或损坏已保存版本；存在恢复内容时应用继续被拒绝，显式保存成功后才转为“已保存未应用”并清除对应恢复状态，放弃只删除恢复的未保存部分且不影响此前草稿、当前目录、既有批次或历史。找回失败不得伪报成功；恢复写入频率和内部存储格式由适配器决定，启动时只显示不阻断的持续“继续编辑”入口，不自动打开编辑器。
- [ ] 无有效目录时禁止绕过目录安装，但历史、缓存和系统优化仍可用。
- [ ] 软件与驱动目录的更新、导入和回退不会联动改变系统设置目录或软件优化目录。
