# 实现软件与驱动目录生命周期

Type: task  
Status: ready-for-agent  
Blocked by: 01, 02

## Goal

加载、更新、导入和回退软件与驱动目录，并在整体错误与局部错误之间采用不同处理。

## Acceptance Criteria

- [ ] 内置目录可离线加载，目录项使用不可变稳定标识。
- [ ] 官网软件目录项明确记录软件发行分支，最新版解析不会跨个人版、企业版或国际版等分支比较版本。
- [ ] 软件目录项可声明交互式或静默安装能力；静默安装方式和结果检测规则均属于受控目录数据，不接受用户输入任意命令。
- [ ] 存在安装阶段偏好时，目录项声明偏好定义、支持的安装器版本、受控执行器引用和结果验证规则；缺少任一必需字段时阻止该项执行，首版必达偏好缺失时阻止发布。
- [ ] 每个软件来源明确标记为可下载文件来源或托管安装来源，目录校验阻止缺少来源类型或必需处理信息的项目执行。
- [ ] 支持主动更新、手动导入、降级预览和上一可用版本回退。
- [ ] 手动导入披露来源无法验证及其可决定管理员操作的风险，用户确认后才加载。
- [ ] 未知字段可忽略；缺少必需字段、无法解析或稳定标识冲突时拒绝整包。
- [ ] 不存在或循环依赖只禁用受影响项，并在页面和日志中说明原因。
- [ ] 目录配置错误项没有强制安装入口，修复后不自动改写旧批次。
- [ ] 无有效目录时禁止绕过目录安装，但历史、缓存和系统优化仍可用。
- [ ] 软件与驱动目录的更新、导入和回退不会联动改变系统设置目录或软件优化目录。
