## Goal

识别当前电脑上可优化的软件，并在标准视图与高级视图中提供清楚、安全且可批量确认的方案选择体验。

## Acceptance Criteria

- [x] 提供独立软件优化一级页面，只展示工作台可靠识别到的已安装软件，不展示未安装软件的方案。
- [x] 页面只承载当前有效精选目录中由目标软件提供或拥有的软件优化方案，不接受任意脚本、命令、注册表项或目标路径，也不混入 Windows 自身的系统优化、卸载、垃圾清理或撤销入口；目标软件提供的资源管理器右键扩展仍留在该软件方案中。
- [x] 官网、Microsoft Store、`winget`、工作台或用户自行安装的软件使用相同的资格判断。
- [x] “外部安装已识别”视为目标软件存在并参与方案发现；方案要求的实际版本仍独立检测，页面保留外部安装标记且不补造来源或工作台安装记录。
- [x] 来源手动交接后仍未检测到的软件以及被用户“暂时跳过”的软件不参与方案发现；用户声明已经安装不能替代工作台检测。
- [x] 打开页面、安装完成或用户主动刷新时重新识别目标软件、版本、方案适用性和当前优化状态。
- [x] 有方案的软件按“可以优化”“需要处理”“已优化”分组；非首版必达目标没有可执行方案时进入默认收起的“暂无可用优化”区域；已安装且版本受支持的首版必达目标缺少方案时显示实现错误并阻止发布验收。
- [x] 页面不使用当前用户、软件账号或整台电脑的范围标签，只用通俗说明描述每个选项实际会改变什么。
- [x] 标准视图显示效果摘要、主要状态、可选项和正常执行入口；高级视图增加实际版本、方案匹配、检测依据和具体修改。
- [x] “强制执行”“强制关闭并继续”和“强制终止优化”只在高级视图显示，标准视图保留原因、安全处理方式和无状态丢失的切换入口。
- [x] 每个方案显示适用版本；版本未知或不匹配时显示“版本不适用”，普通执行不可用，高级视图的强制执行准确披露风险并单独确认。
- [x] 要求目标软件退出时先提示正常关闭并重新检测；强制关闭与强制终止优化使用不同名称、确认和记录，仍无法确认目标软件退出时保持阻止状态。
- [x] 一个方案可包含多个选项，低影响推荐项默认勾选，高影响项默认不勾选，必需操作清楚标记且不能取消。
- [x] 每个方案保留可查看的说明来源；来源网页变化不会在页面打开或刷新时直接改变方案，只有软件优化目录版本更新后才变化。
- [x] 非首版必达项暂时不能自动处理时显示“暂不支持自动处理”，提供目标软件中的手动设置入口和来源链接，不作为自动步骤提交到批次；首版必达项不得使用该状态通过发布验收。
- [x] 首版必达项只有在已实现的受控路径运行时失败或遇到未识别的新版本后才显示手动应急处理；该入口不能作为正常选择提交，也不能产生工作台执行成功记录。
- [x] 只把用户实际选中的选项提交给批次；未选择内容在摘要中明确区分，没有可执行选项时禁用开始命令并说明原因。
- [x] 方案级和选项级必需关系或冲突在选择时显示，自动调整前取得用户确认，执行前不存在可预先识别的冲突。
- [x] 已符合目标的选项显示“已优化”并跳过重复修改，同时允许查看检测依据。
- [x] 目标软件版本变化后重新检查；失效项显示“需要重新优化”，超出范围显示“版本不适用”，不会自动再次优化。
- [x] 推荐流程第四阶段预选所有适用软件中的低影响推荐项，高影响项保持未选；用户明确提交前不创建批次。
- [x] 多软件正常优化只显示一次按软件分组的确认摘要，逐个列出目标软件、实际选项、影响、关闭和重启要求；额外强制风险在实际触发前分别确认。
- [x] 普通下架或紧急撤回方案不能新执行；页面显示原因、受影响内容和当前通知状态，并只为当前仍可执行的结果生成交给事项 27 的重试请求，不自行创建批次。
- [x] 安装完成后的“可以优化”提示非阻塞、可收起且不永久忽略方案，也不会反复弹出。
- [x] 软件优化页只显示当前状态和最近一次结果，并生成包含稳定记录标识的历史导航意图；在“历史与日志”页实际定位同一完整记录由事项 15 负责。
