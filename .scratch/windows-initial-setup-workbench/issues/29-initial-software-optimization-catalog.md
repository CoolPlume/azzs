# 补充首版软件优化方案清单

Type: task  
Status: ready-for-agent  
Blocked by: 25

## Goal

把已确认的搜狗输入法安装后优化方案完整整理为首版正式目录内容，并确保其全部选项都能由工作台受控执行和检测；以后补充的其他软件方案作为后续目录扩展，不阻塞本事项。

## Engineering Work Required

- 开发者需要至少针对事项 19 冻结的当前稳定搜狗安装器基线所产生的已安装版本，确定每个已确认选项的受控执行方式、状态检测、失败识别和自动化检查，并把规则冻结进版本化目录与执行器。
- 可以使用官方设置方式、搜狗自身配置修改或目录限定的界面自动操作；具体技术路径属于工程研究，不再等待维护者提供注册表、配置路径或界面定位细节。
- 只有在已经实现的受控路径运行时失败或遇到未识别的新版本时，才为用户提供准确的手动应急处理；其内容不能替代首版实现。
- 除搜狗输入法外的目标软件、优化目标和运行约束由维护者以后补充，不属于本事项完成前提。

## Confirmed Content

- 搜狗输入法方案以维护者文章 [搜狗输入法安装配置](https://coolplume.github.io/posts/f4654180.html) 为说明来源，并关联 [搜狗输入法 Windows 官网](https://shurufa.sogou.com/windows)；网页只用于说明和维护参考，可执行内容冻结在软件优化目录版本中。
- 搜狗输入法安装阶段的“关闭搜索候选”和“不安装腾讯元宝”由事项 19 的软件安装目录承载，不在安装后优化方案中重复执行。
- 安装后方案逐项提供以下外观与输入习惯选项：隐藏状态栏、关闭“显示输入法指示器”、关闭“状态栏嵌入语言栏”、关闭“标点配对：自动补全成对标点”、关闭“智能调整数字后标点”以及调整候选词个数。
- 安装后方案提供关闭账户中的“系统功能快捷键”。
- 高级设置逐项提供：关闭输入助手总开关、关闭开机自动启用、关闭 i 模式换肤、关闭皮肤推荐、关闭皮肤弹泡推荐、关闭桌面右下角推荐以及关闭搜索推荐。
- AI 汪仔逐项提供：关闭等号搜索、AI 表情、快捷搜索、划词工具、快捷键唤起 AI 汪仔以及自启动 AI 汪仔。
- 候选提示设置逐项提供：关闭快速搜索和关闭工具箱。
- 系统右键扩展管理逐项提供：关闭搜狗输入法提供的 PDF 工具、磁盘管理和压缩；这些扩展归入搜狗软件优化，不因出现在资源管理器中改归系统优化。
- 广告、推荐、弹窗和自启动相关的低影响项目默认勾选；状态栏外观、输入习惯、候选词数量、标点、快捷键、输入助手总开关、i 模式换肤、除自启动外的 AI 功能、候选提示工具和搜狗右键扩展默认不选。所有非必需选项都允许用户调整。
- 上述每一个安装后选项都是首版必达项：在声明支持的搜狗输入法版本中必须具有工作台受控执行和结果检测规则，不得以“暂不支持自动处理”“暂无可用优化”、打开设置页或手动说明代替。
- 遇到未识别的新版本或已实现路径的运行时失败时，方案保留真实的“版本不适用”“优化失败”或“优化结果待确认”状态，并可附手动应急处理；手动操作不得记录成工作台自动执行成功。
- 文章内容变化不会自动修改方案；维护者审核并发布新的软件优化目录版本后，新增或变更的执行规则才可供用户选择。

## Acceptance Criteria

- [ ] 每个目标软件具有可靠的安装和版本检测规则；不按当前用户、软件账号或整台电脑分类或排除方案。
- [ ] 首版目录至少声明并支持事项 19 冻结的当前稳定搜狗安装器基线所产生的已安装版本；不得以空版本范围绕过全部选项的首版能力门槛。
- [ ] 每个方案和选项使用稳定标识，并声明适用软件版本、实际效果、风险、默认选择及选项关系。
- [ ] 非首版必达目标没有可执行方案时可以使用“暂无可用优化”描述；已安装且版本受支持的搜狗输入法不得进入“暂无可用优化”或“暂不支持自动处理”。
- [ ] 搜狗输入法方案逐项覆盖“Confirmed Content”中的所有安装后设置，安装阶段选项只与事项 19 关联而不重复执行。
- [ ] 搜狗提供的 PDF 工具、磁盘管理和压缩右键扩展归入搜狗方案；Windows 自身的菜单和资源管理器样式不在本目录收录。
- [ ] 搜狗方案的低影响默认项、偏好类默认未选项、每项可调选择及来源展示与已确认规则一致。
- [ ] 每一个已确认搜狗选项都具有符合官方方式优先、自身配置其次、目录限定界面自动操作最后这一边界的受控执行方式。
- [ ] 每一个已确认搜狗选项都具有可验证的目标状态；运行时无法得出结论时进入“优化结果待确认”，不能把实现缺失降级为用户确认。
- [ ] 已实现路径的运行时失败和未识别新版本可以显示手动应急处理，但它不作为正常执行步骤、不产生成功记录，也不计入事项完成。
- [ ] 每个正式方案提供执行前确认所需的效果、影响、关闭软件和重启信息，并通过事项 25 定义的模式及局部规则校验，不产生“目录配置错误”。
- [ ] 完整搜狗输入法方案及其全部已确认选项提供足够且有效的目录数据、执行器、检测器和自动化检查，可供事项 22 在条件允许时补充发现、选择、确认、执行、验证、历史和必要失败场景的真实设备证据。
- [ ] 目录不接受用户提供的任意脚本、命令、注册表项、配置路径或界面操作步骤；只使用目录预定义的受控方式，并排除软件卸载、垃圾清理和主要属于 Windows 的系统设置。
