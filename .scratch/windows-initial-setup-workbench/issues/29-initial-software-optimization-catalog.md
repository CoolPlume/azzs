# 补充首版软件优化方案清单

Type: task  
Status: needs-info  
Blocked by: 25

## Goal

把已确认的搜狗输入法优化方案及维护者稍后提供的其他方案整理为首版正式目录内容，并至少提供一组可端到端验收的方案。

## Information Needed

- 除搜狗输入法外，首版还要支持的软件及具体优化目标。
- 搜狗输入法各已确认选项在不同软件版本中的受控执行方式、状态检测和必要的手动入口。
- 其余目标软件和方案的适用版本、选项、默认状态、必需关系、冲突和风险级别。
- 其余方案的目标软件退出、强制关闭、Windows 重启及执行后检测要求。

## Confirmed Content

- 搜狗输入法方案以维护者文章 [搜狗输入法安装配置](https://coolplume.github.io/posts/f4654180.html) 为说明来源，并关联 [搜狗输入法 Windows 官网](https://shurufa.sogou.com/windows)；网页只用于说明和维护参考，可执行内容冻结在软件优化目录版本中。
- 搜狗输入法安装阶段的“关闭搜索候选”和“不安装腾讯元宝”由事项 19 的软件安装目录承载，不在安装后优化方案中重复执行。
- 安装后方案逐项提供以下外观与输入习惯选项：隐藏状态栏、关闭“显示输入法指示器”、关闭“状态栏嵌入语言栏”、关闭“标点配对：自动补全成对标点”、关闭“智能调整数字后标点”以及调整候选词个数。
- 安装后方案提供关闭账户中的“系统功能快捷键”。
- 高级设置逐项提供：关闭输入助手总开关、关闭开机自动启用、关闭 i 模式换肤、关闭皮肤推荐、关闭皮肤弹泡推荐、关闭桌面右下角推荐以及关闭搜索推荐。
- AI 汪仔逐项提供：关闭等号搜索、AI 表情、快捷搜索、划词工具、快捷键唤起 AI 汪仔以及自启动 AI 汪仔。
- 候选提示设置逐项提供：关闭快速搜索和关闭工具箱。
- 系统右键扩展管理逐项提供：关闭搜狗输入法提供的 PDF 工具、磁盘管理和压缩；这些扩展归入搜狗软件优化，不因出现在资源管理器中改归系统优化。
- 广告、推荐、弹窗和自启动相关的低影响项目可默认勾选；状态栏外观、输入习惯、候选词数量、标点、快捷键、输入助手总开关、i 模式换肤、除自启动外的 AI 功能、候选提示工具和搜狗右键扩展默认不选。所有非必需选项都允许用户调整。
- 暂时无法可靠自动处理的已确认选项仍保留并显示“暂不支持自动处理”、搜狗中的手动设置入口和文章来源，不静默省略，也不作为自动步骤进入批次；用户手动处理后，未经检测或确认不得显示“已优化”。
- 文章内容变化不会自动修改方案；维护者审核并发布新的软件优化目录版本后，新增或变更的执行规则才可供用户选择。

## Acceptance Criteria

- [ ] 每个目标软件具有可靠的安装和版本检测规则；不按当前用户、软件账号或整台电脑分类或排除方案。
- [ ] 每个方案和选项使用稳定标识，并声明适用软件版本、实际效果、风险、默认选择及选项关系。
- [ ] 没有可执行方案的软件使用“暂无可用优化”目标描述；已确认但不支持自动处理的项目保持可见并提供手动入口。
- [ ] 搜狗输入法方案逐项覆盖“Confirmed Content”中的所有安装后设置，安装阶段选项只与事项 19 关联而不重复执行。
- [ ] 搜狗提供的 PDF 工具、磁盘管理和压缩右键扩展归入搜狗方案；Windows 自身的菜单和资源管理器样式不在本目录收录。
- [ ] 搜狗方案的低影响默认项、偏好类默认未选项、每项可调选择及来源展示与已确认规则一致。
- [ ] 执行方式符合官方方式优先、自身配置其次、界面自动操作最后的受控边界。
- [ ] 每个选项具有可验证的目标状态；无法自动检测时提供准确的用户确认说明。
- [ ] 每个正式方案提供执行前确认所需的效果、影响、关闭软件和重启信息，并通过事项 25 定义的模式及局部规则校验，不产生“目录配置错误”。
- [ ] 至少一组正式方案提供足够且有效的目录数据，可供事项 22 验收发现、选择、确认、执行、验证、历史和必要的失败或重启场景。
- [ ] 目录不接受用户提供的任意脚本、命令、注册表项、配置路径或界面操作步骤；只使用目录预定义的受控方式，并排除软件卸载、垃圾清理和主要属于 Windows 的系统设置。
