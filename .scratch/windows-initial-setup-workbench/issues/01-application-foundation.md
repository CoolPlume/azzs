## Goal

确定首版实现基线，并建立以 Windows 10 22H2 为最低目标版本、覆盖 x64 与 ARM64 的应用骨架。

## Acceptance Criteria

- [ ] 技术选择及难以逆转的取舍已记录为 ADR。
- [ ] Windows 界面使用 WinUI 3、C++/WinRT 与 XAML，初始化核心使用 C++26，发行不依赖 .NET。
- [ ] 界面宿主按 Windows 每显示器 DPI 与显示缩放工作，4K、225% 显示缩放和混合 DPI 多显示器不要求重启；Windows 负责图形适配器选择，集成、独立和混合图形设备均不成为功能前提，视觉增强可安全回退但不影响命令、状态或无障碍。
- [ ] 界面层与 C++ 核心层在同一桌面应用内通过明确接口分离，不创建独立后台服务。
- [ ] 建立界面适配器、应用核心、可移植领域模块、Windows/基础设施适配器和唯一装配入口组成的模块化单体骨架，具体实现只在装配入口连接。
- [ ] 核心接口不暴露 WinUI 3 控件或页面类型，界面不复制业务规则。
- [ ] 界面只提交用户意图并投影核心状态，不直接操作注册表、配置、下载、进程或安装器；核心状态是唯一业务事实来源。
- [ ] 可移植 C++ 核心不依赖 WinUI 3 或 Win32 类型，Windows 专属能力通过平台适配边界接入。
- [ ] Windows 平台适配层提供由 C++ 核心统一规划的注册表、配置、进程与状态检测，以及范围受限的安装器和软件设置界面自动操作能力；该自动操作不得读取、代填、传递或保存登录、注册、验证码、付款或个人资料内容，相关步骤只由用户在软件厂商官方界面完成。WinUI 3 界面不自行复制执行规则。
- [ ] 缺少受控执行方式的首版必达项会阻止发布，不能降级为说明链接或用户手动操作。
- [ ] 模块依赖单向且无环，不通过全局可变业务状态、服务定位器或万能 `Utils`/`Manager` 绕过接口。
- [ ] 普通目录内容扩展无需修改现有页面和核心流程；新的操作类型只通过项目内置受控能力扩展接入，不建立第三方代码插件入口。
- [ ] 核心骨架可以在不启动 WinUI 3 和不访问真实系统资源时使用测试适配器运行，供事项 31 建立合同与架构门禁。
- [ ] 核心拥有仅用于无系统修改、可独立合并结果的 CPU 密集型工作的受限并行调度；页面和适配器不得自行建立竞争性工作线程，安装、系统优化、软件优化、状态提交、结果确认和恢复仍使用同一受控操作占用与串行边界。
- [ ] 首版不构建通用跨平台界面或 macOS 发行物。
- [ ] C++ 核心使用 C++26 编译模式；选用的新特性在稳定工具链中同时覆盖 x64 与 ARM64。
- [ ] 界面宿主也使用 C++26 编译模式，C++/WinRT 和 XAML 工具链不稳定支持的特性不进入界面代码。
- [ ] WinUI 3、Windows App SDK、编译器、SDK 和依赖选择实施时最新且满足产品约束的稳定版本。
- [ ] 发布工具与依赖版本已固定，试验性能力没有进入稳定接口或持久化格式。
- [ ] 建立由本事项唯一拥有的早期 Windows CI 工作流：同仓库拉取请求指向 `codex/v1-integration` 时运行，合并进入该集成分支或 `main` 后重跑，并允许人工触发；事项 31 只提供被调用的架构与测试命令，不复制工作流。
- [ ] 早期 CI 使用 GitHub 托管 Windows runner 和默认只读权限，不使用 `pull_request_target`、secrets、写权限或 self-hosted runner；第三方 Action 固定到精确提交，不可信 pull request 或 fork 不能取得发布能力。
- [ ] CI 对 x64 执行构建与无界面 smoke，对 ARM64 完成编译链接；只保留日志、测试报告和构建清单，事项 21 前不上传可下载应用二进制，也不创建 tag 或 GitHub Release。
- [ ] 应用启动时申请 UAC 管理员权限，并在会话内保持管理员身份。
- [ ] 软件安装、系统优化和软件优化都只能执行当前有效精选目录中的受控操作，不能借管理员会话接受任意命令、脚本或目标路径。
- [ ] 默认进入概览页，七个一级页面均可导航且可独立进入，其中软件优化与系统优化、软件安装相互区分。
- [ ] 首版显示简体中文，界面文案保留后续增加语言的能力。
- [ ] 便携版和安装版的开发、测试与打包入口已建立。
- [ ] x64 与 ARM64 构建目标已建立，运行时依赖无需目标系统预装。
- [ ] 早于 Windows 10 22H2 时显示版本风险警告但允许继续，不以版本号硬性阻止启动。
- [ ] 没有把最低目标版本描述成经过兼容性测试的保证。
- [ ] 关闭工作台后不存在继续启动新任务的后台服务，重新打开时等待用户明确继续。
