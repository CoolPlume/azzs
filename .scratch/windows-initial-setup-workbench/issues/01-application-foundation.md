# 建立应用基础与页面框架

Type: task  
Status: ready-for-agent

## Goal

确定首版实现基线，并建立以 Windows 10 22H2 为最低目标版本、覆盖 x64 与 ARM64 的应用骨架。

## Acceptance Criteria

- [ ] 技术选择及难以逆转的取舍已记录为 ADR。
- [ ] Windows 界面使用 WinUI 3、C++/WinRT 与 XAML，初始化核心使用 C++26，发行不依赖 .NET。
- [ ] 界面层与 C++ 核心层在同一桌面应用内通过明确接口分离，不创建独立后台服务。
- [ ] 核心接口不暴露 WinUI 3 控件或页面类型，界面不复制业务规则。
- [ ] 可移植 C++ 核心不依赖 WinUI 3 或 Win32 类型，Windows 专属能力通过平台适配边界接入。
- [ ] Windows 平台适配层提供由 C++ 核心统一规划的注册表、配置、进程与状态检测，以及范围受限的安装器和软件设置界面自动操作能力；WinUI 3 界面不自行复制执行规则。
- [ ] 缺少受控执行方式的首版必达项会阻止发布，不能降级为说明链接或用户手动操作。
- [ ] 首版不构建通用跨平台界面或 macOS 发行物。
- [ ] C++ 核心使用 C++26 编译模式；选用的新特性在稳定工具链中同时覆盖 x64 与 ARM64。
- [ ] 界面宿主也使用 C++26 编译模式，C++/WinRT 和 XAML 工具链不稳定支持的特性不进入界面代码。
- [ ] WinUI 3、Windows App SDK、编译器、SDK 和依赖选择实施时最新且满足产品约束的稳定版本。
- [ ] 发布工具与依赖版本已固定，试验性能力没有进入稳定接口或持久化格式。
- [ ] 应用启动时申请 UAC 管理员权限，并在会话内保持管理员身份。
- [ ] 软件安装、系统优化和软件优化都只能执行当前有效精选目录中的受控操作，不能借管理员会话接受任意命令、脚本或目标路径。
- [ ] 默认进入概览页，七个一级页面均可导航且可独立进入，其中软件优化与系统优化、软件安装相互区分。
- [ ] 首版显示简体中文，界面文案保留后续增加语言的能力。
- [ ] 便携版和安装版的开发、测试与打包入口已建立。
- [ ] x64 与 ARM64 构建目标已建立，运行时依赖无需目标系统预装。
- [ ] 早于 Windows 10 22H2 时显示版本风险警告但允许继续，不以版本号硬性阻止启动。
- [ ] 没有把最低目标版本描述成经过兼容性测试的保证。
- [ ] 关闭工作台后不存在继续启动新任务的后台服务，重新打开时等待用户明确继续。
