# 实现调试模式与图形化软件目录编辑器

Type: task  
Status: ready-for-agent  
Resolution: open
Blocked by: 02, 03, 15, 18, 24, 31
Owner: issue-32
Consumers: 21, 22
Verification: 目录编辑状态机、TOML 往返、保存、恢复、应用负例、脱敏诊断及 UI 与架构合同测试。
Evidence freshness: 绑定当前提交、目录、日志、导出模式和 WinUI 环境；相关状态或格式变化后重跑。

## Goal

提供可即时开启的调试模式，以极详细且已脱敏的本机日志降低诊断成本，并让项目维护者通过 WinUI 3 图形界面维护同一软件目录模型。

## Ownership Boundary

本事项拥有调试模式状态、目录编辑会话及其类型化意图；设置页宿主由事项 18 拥有，设备级事件、偏好持久化与日志存储由事项 02 拥有，历史和诊断资料读取与导出由事项 15 拥有，当前有效目录、草稿内容与校验规则由事项 03 拥有。本事项不另存日志粒度、目录草稿或当前有效目录，只通过这些 owner 的接口协调编辑器场景。

## Acceptance Criteria

- [ ] 向事项 18 暴露默认关闭、即时生效的调试模式状态和类型化切换意图，并经事项 02 的偏好接口跨应用重启保留；三类目录手动导入只在本事项的调试工具投影中可用，普通和高级视图不获得绕过入口。
- [ ] 调试模式开启时通过事项 02 的单一日志接口请求最高可用粒度，并显示该接口返回的实际粒度与限制；本事项不自行记录事件、不另存日志级别，也不把未取得的具体原因补写为成功或完整。
- [ ] 编辑器、导入和调试状态不得绕过事项 02 的集中脱敏与本机保留边界；凭据、身份和路径规则只有一份，具体写入测试由事项 02、读取与导出测试由事项 15 拥有。
- [ ] 向事项 18 提供调试影响、日志位置、诊断导出、清空和编辑器入口所需的只读投影与命令；日志查看、单文件导出内容及采集缺口由事项 15 拥有，关闭调试模式只改变事项 32 的状态并请求事项 02 恢复普通粒度。
- [ ] 调试模式开启后显示独立图形化软件目录编辑器，可查看、搜索、添加、复制、修改、启用、禁用和删除软件条目，并维护模式支持的分类、依赖、版本、来源、离线安排、说明与本地化字段。
- [ ] 编辑器使用与 `catalog/software-catalog.toml` 相同的版本化领域模型和核心校验；界面只提交类型化编辑意图，不直接解析或写入 TOML，也不建立数据库或界面私有格式。
- [ ] 编辑内容形成独立的目录编辑草稿；“保存草稿”只保存候选内容并显示“已保存未应用”，不改变当前软件列表、选择、规划或执行。已经保存但尚未应用的草稿跨正常关闭和重新打开保留，重开后仍显示“已保存未应用”，并可继续编辑、明确应用或删除；任何恢复都不得自动应用，删除草稿也不得改变当前有效目录、既有批次或历史。同一次运行中的未保存修改继续由核心保留；切换页面、切换标准视图与高级视图或关闭调试模式后重新打开编辑器，仍显示“未保存更改”。
- [ ] 工作台异常退出或电脑断电后，下次启动应尽量找回目录编辑器尚未保存的修改；成功找回的内容明确标为“恢复的未保存修改”，仍属于未保存状态，绝不自动保存或应用。恢复的未保存修改、已保存未应用草稿和当前有效目录分别建模，找回不得覆盖或损坏已保存版本；恢复失败不得显示或记录为已找回。本事项不规定恢复写入频率和内部存储格式；启动时只显示不阻断的持续“继续编辑”入口，不自动打开编辑器。
- [ ] “应用”只处理当前已保存草稿；存在普通或恢复的未保存更改时提示先保存，界面禁用且核心拒绝应用，既不能应用旧草稿也不能隐式保存恢复内容。显式保存恢复内容成功后才转为“已保存未应用”并清除对应恢复状态；保存失败继续保留恢复内容且不得部分覆盖此前已保存版本，放弃只移除恢复的未保存部分，不影响此前草稿、当前目录、既有批次或历史。切换页面、切换标准视图与高级视图或关闭调试模式不得弹出关闭确认，也不得自动保存、放弃或应用；只有用户主动关闭整个工作台时才提供“保存草稿并关闭”“放弃未保存修改”和“返回编辑”。保存成功后才关闭，放弃只恢复上次保存内容并保留已有草稿，返回编辑取消关闭，任何结果都不得应用目录。若调试模式已关闭，保存失败或返回编辑临时恢复原编辑会话，但不重新开启调试模式或极详细日志，再次离开后入口继续隐藏；该临时会话只允许编辑、保存或放弃，“应用”保持禁用且核心拒绝直接调用，并提示先明确重新开启调试模式。每次正常应用或调试模式手动导入时分别重新计算运行时加载结果和正式发布门禁结果；整包级运行时错误、未知执行语义、允许加载但须禁用项目的局部依赖错误及仅发布级问题必须分组准确定位，不能从本机加载结果推断发布结论；保存后再次编辑不能复用旧校验结果。
- [ ] 整包运行时校验成功后一次性替换当前有效目录并只影响之后的软件列表、规划和新建批次；整包失败或未知执行语义时保留原当前有效目录、草稿和错误，不允许强制应用。局部依赖错误随整份新目录切换，受影响项按新目录禁用且不混入旧定义，这不属于部分应用。运行时通过但 `release_state = "draft"` 或存在其他仅发布级问题时，命令明确显示“应用为本机试用目录”；应用不修改 `release_state` 或发布结论，本机试用身份属于同一当前有效目录。执行中、暂停、等待确认、等待重启或待恢复的批次及历史继续使用原快照。
- [ ] 本机试用目录应用后，标准视图与高级视图的软件安装页、推荐流程软件阶段、设置页的软件与驱动目录当前状态及编辑器持续显示未发布身份；关闭调试模式时只隐藏图形化编辑器和手动导入入口，重新启动后按已保存的调试模式状态决定入口是否显示，无论入口是否显示都不撤销目录或隐藏该状态。编辑器状态切换只礼貌播报一次且焦点留在“应用”，不用颜色单独编码，也不使用绿色完成、勾选、Toast、音效、淡入、弹跳或庆祝动效。
- [ ] 编辑器不接受任意命令、脚本、解析代码、插件或未建模安装参数，调试模式不能绕过风险确认、恢复、执行互斥或安全规则，也不能修改或伪造正式发布门禁结果、让本机试用目录进入发行制品。
- [ ] 编辑工作台使用适合反复维护的密集列表与详情布局，字段控件与数据类型匹配，长文字和错误在窄窗口、4K、225% 显示缩放及常用文本缩放下不重叠；窗口跨不同 DPI 或显示缩放的显示器移动、原显示器断开后，焦点、未保存修改、滚动语义和当前目录身份保持，窗口仍可见。
- [ ] 高频编辑、筛选、选择、校验和日志刷新即时完成，不播放页面、逐项错峰、缩放或弹簧动效；鼠标、键盘、触摸和屏幕阅读器均可完成主要编辑流程。
- [ ] 无界面测试覆盖目录增删改、保存不生效、已保存未应用草稿跨正常关闭、异常退出、断电后重新打开保留且不自动应用、仅有已保存草稿时关闭不弹未保存确认、重开后的已保存草稿可继续编辑或明确应用、删除草稿不改变当前目录和既有记录、同一次运行中切换页面、切换标准视图与高级视图及关闭调试模式均不弹关闭确认、不丢失修改且不自动保存或应用、重新打开编辑器仍显示未保存状态、已有已保存草稿后产生未保存修改时应用请求被拒绝且既不应用旧草稿也不隐式保存新修改、未保存修改下主动关闭的三项选择、保存成功关闭后重开为更新后的“已保存未应用”且当前有效目录不变、保存失败保持打开且不部分覆盖此前已保存版本、放弃只回到此前草稿、返回编辑取消关闭且所有路径均不应用目录、调试模式关闭后的临时编辑会话只允许编辑、保存或放弃且应用请求在界面与核心中均被拒绝、正常应用时重新校验、运行时整包失败时保留旧目录和草稿、运行时通过但发布未通过时切换并标记本机试用、关闭调试模式不撤销身份、发布流程仍拒绝、既有批次快照不变、TOML 兼容往返、调试粒度切换与敏感信息脱敏；另覆盖异常退出和断电后尽量找回未保存修改、恢复内容明确标示且与已保存草稿及当前目录隔离、应用拒绝、显式保存后的状态迁移和恢复状态清除、保存失败保护旧版本、只放弃恢复部分及找回失败不伪报成功。合同与架构检查证明 WinUI 3 不直接依赖文件、日志或执行适配器。
- [ ] 八个发行制品均提供相同行为且无需额外开发运行时：标准版提供 x64 与 ARM64 的便携版和安装版，断网救援版与超大离线版各提供 x64 与 ARM64 的便携版。
