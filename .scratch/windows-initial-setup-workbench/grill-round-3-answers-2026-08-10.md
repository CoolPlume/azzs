# 第三轮答案登记

Status: resolved  
Date: 2026-08-10

本轮继续 `grill-with-docs`，只收口已经进入前沿的用户可见产品取舍；不开始产品代码、构建、发布或真实设备验证。

## 已确认答案

- Q20：选择方案 1。工作台内的一键更新只列出正式稳定发行；用户仍可自行前往 GitHub 查看或手动下载其他公开内容。
- Q21：选择方案 1。正式产品名称为“Windows 初装工作台”，使用简洁的设备准备图形作为产品图标方向；`azzs` 继续只是仓库标识。
- Q22：按优先级采用方案 3、2、1。对受控安装档案已知且可可靠处理的安装器交互项，工作台优先自动处置；无法自动处置时先在工作台内明确确认；仍无法可靠处理时交给官方安装界面由用户完成。该层级作为一般交互处置原则，不把任何层级的记录表述为条款、隐私或来源已经得到验证；第四轮 Q23 进一步明确账户与个人资料步骤一律直接交给官方安装界面中的用户。

## 同步结果

- ADR-0006 固定一键更新仅显示正式稳定发行。
- ADR-0040 固定第三方安装器交互的自动、确认和官方界面三层处置。
- `CONTEXT.md`、首版规格、维护指南、公开仓库说明和相关事项均使用正式产品标识，并记录安装器交互与一键更新的边界。

真实设备验证仍按 ADR-0034 记录“未实机验证”，不构成发布阻断。
