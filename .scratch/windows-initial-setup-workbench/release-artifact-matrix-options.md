# 三档发行制品矩阵选项

Status: resolved  
Decision: Q7 = 2  
Last updated: 2026-08-10

三档内容版、两种打包形态和两种处理器架构是三个独立维度。本文把可选矩阵展开，避免用“在线/离线版”或“12 个包”掩盖实际构建、维护与发行成本。

## 1. 固定维度

| 维度 | 值 | 不能混用的概念 |
| --- | --- | --- |
| 内容版 | 标准版、断网救援版、超大离线版 | 不决定安装/便携或处理器架构 |
| 打包形态 | 便携版、安装版 | 不决定携带多少第三方资源 |
| 发行架构 | x64、ARM64 | 不等于系统架构或某个软件包架构 |

所有制品使用同一工作台核心、安全边界和默认选择；内容版只改变可用资源。超大离线版携带某软件也不表示默认勾选或适用于当前硬件，更不表示来源、安全、身份或第三方权利已经验证。

## 2. 方案 1：完整笛卡尔积

每个内容版都提供便携/安装与 x64/ARM64，共 12 个成品。

| 内容版 | x64 便携 | ARM64 便携 | x64 安装 | ARM64 安装 |
| --- | ---: | ---: | ---: | ---: |
| 标准版 | 是 | 是 | 是 | 是 |
| 断网救援版 | 是 | 是 | 是 | 是 |
| 超大离线版 | 是 | 是 | 是 | 是 |

优点：选择规则最规则，任何用户都能找到同内容版的安装/便携形态。代价：救援/超大离线通常面向 U 盘和一次性首装，安装版使用场景尚未证明；大资源会在安装器与便携包中重复，12 个成品都需要构建清单、升级/卸载安排和发行记录。

适用前提：维护者明确需要把救援与超大离线内容长期安装到设备，并愿意承担完整矩阵的发布成本。

## 3. 已选方案 2：按使用场景提供 8 个成品

标准版提供两种打包形态；救援和超大离线只提供便携版，共 8 个成品。

| 内容版 | x64 便携 | ARM64 便携 | x64 安装 | ARM64 安装 |
| --- | ---: | ---: | ---: | ---: |
| 标准版 | 是 | 是 | 是 | 是 |
| 断网救援版 | 是 | 是 | 否 | 否 |
| 超大离线版 | 是 | 是 | 否 | 否 |

优点：仍是单下载、解压/安装即可用；常规长期使用有安装版，U 盘救援不复制成安装器；矩阵比方案 1 少三分之一。代价：需要向用户明确只有标准版可安装；以后若出现救援安装场景，要新增制品和升级路径。

维护者已选择方案 2。它不改变 x64 与 ARM64 各自的制品范围，也不允许 ARM64 用户拿 x64 工作台制品凑合；尚未实机验证的情形按 ADR-0034 记录，不阻断公开发行。

## 4. 方案 3：应用与资源包分离

发布 4 个标准应用制品，再发布按架构或内容拆分的救援/超大离线资源包；用户下载后由工作台导入或由发布工具装配。

优点：工作台二进制只发布一次，资源更新可以独立；安装版和便携版可共享资源，减少重复上传。代价：首次使用不再是一个完整下载；必须新增资源包版本兼容、导入、磁盘空间、部分失败和用户选择流程，并扩大资源与应用版本错配的产品复杂度。

当前不建议首版采用。只有资源包生命周期、版本兼容和导入体验已经成为明确产品需求时，才值得用新增复杂度换发布体积。

## 5. 无论选哪种方案都必须固定

### 命名与身份

每个成品名至少编码产品版本、内容版、打包形态、发行架构。显示名可以中文，机器标识保持稳定且不依赖“最新版”。

### 资源清单

每个成品生成构建清单，列出实际装入的候选资源、可取得的版本和架构以及所属内容版；未知事实如实标为未知。清单不提供摘要、签名、发布者、许可证或来源验证资料，也不把这些事实当作公开发行资格。

### 测试矩阵

每个精确制品的开发者发布证据分别记录已完成的自动检查，以及 x64/ARM64、便携/安装、断网、救援、超大离线和 SmartScreen/UAC 情形是否已实机验证。未做实机验证时必须写为“未实机验证”，不能借其他制品的结果外推，也不因此阻断公开发行。

### 发布门禁

候选资源是否随包或公开发布不受 `accepted`、许可证据、来源身份、再分发结论或实机验证状态阻断。救援伴随工具仍受 Q2 的受控制品边界约束；目录仍为 `draft`、制品无法按声明启动或其他结构性发行条件未满足时，才不能作为正式制品。Q7 的选择只冻结容器拓扑和命名，不改变资源事实记录的含义。

## 6. 已确认结果

Q7 已确认采用方案 2：标准版提供 x64、ARM64 的便携版和安装版；断网救援版与超大离线版各提供 x64、ARM64 的便携版。Q2 与 Q3 已确认。Q4、Q8、Q9、Q10 的决定不阻断制品拓扑；Q7 只冻结制品形态与数量，不要求每种制品携带相同资源。
