# 第四轮 Grill 答案登记

Status: resolved  
Date: 2026-08-10  
Scope: 第三轮决定派生出的账户交互、应用更新与公开简介前沿

## 已确认决定

- Q23：选择方案 1。登录、注册、验证码、付款和个人资料步骤一律由用户在官方安装界面完成；工作台不代填、读取或保存其内容。
- Q24：选择方案 1。已识别且可可靠处置的附加推广默认拒绝；无法可靠处置时沿 Q22 的“受控自动处置 -> 工作台交互确认 -> 官方安装界面”逐级回退。
- Q25：选择方案 1。当前运行测试发行时，工作台提供用户主动的“切换到最新稳定版”操作，不自动降级或替换。
- Q26：选择方案 1。缺少同发行架构、内容版和便携版或安装版形态的正式稳定制品时，明确显示不能自动更新并提供 GitHub 手动下载入口，不自动换用其他制品。
- Q27：选择方案 1。GitHub 仓库与 Release 使用产品简介：“Windows 初装工作台：帮助新装 Windows 完成驱动准备、系统优化、常用软件安装和软件优化。”

## 同步边界

- Q23-Q24 收紧 ADR-0040 的安装器交互范围，不重开 Q4 的项目级信任门槛或 Q22 的一般回退层级。
- Q25-Q26 补充 ADR-0006 的用户主动稳定版切换和匹配制品规则，不替代尚待工程合同收口的更新健康检查。
- Q27 只确定公开简介，不把尚未实现的产品功能、真实设备验证或公开 Release 写成既成事实。
