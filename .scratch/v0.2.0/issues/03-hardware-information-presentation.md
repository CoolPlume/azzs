Status: ready-for-human

## 问题

0.1.1 `f2f1998` 将大量硬件推断拼进显示字符串，包括未分类物理磁盘、存储接口/PCIe/NAND 颗粒、资料识别和显示器“物理刷新率上限（EDID）”标签；硬件值使用不可选择的文本，且没有统一“项目 | 信息”表头。

## 目标

- 统一显示机型、Windows 版本、CPU、主板、内存、显卡、显示器、固态硬盘、机械硬盘、有线网卡、无线网卡、声卡、NPU。
- CPU 摘要固定显示性能核、能效核和低功耗能效核三段；仅当 Windows 可靠确认两类或三类拓扑且总数一致时显示 `N性能核+N能效核+N低功耗能效核`，缺失类别为 `0`；拓扑不可获取、单一 `EfficiencyClass` 或计数不一致时三段均显示“未识别”，不猜测或以 `0` 代替未知。
- 删除未分类物理磁盘行；固定摘要无事实显示“未识别”，空的多实例类别隐藏。
- 显示器使用 `型号（分辨率；Hz；内建/外接；英寸）` 四槽形式；英寸优先由可验证的 EDID 物理尺寸换算，缺失、无效或冲突时才回退到活动 WMI 物理尺寸；回退必须按完整 PNP 实例精确匹配，不能按同型号串用。无法可靠取得时显示对应“未识别”字段而不猜测或省略，且不显示原始 EDID、完整 PNP 实例标识或来源推断标签。
- 固态硬盘只显示型号/容量等直接事实，不显示接口、PCIe、NAND 颗粒或资料识别推断。
- 所有硬件信息可选择复制，并提供复制本节命令；剪贴板不进入核心状态。
- 继续由 Windows 适配器集中执行 ADR-0049 的物理存在确认，页面不重复过滤。

## 验收

- 复制单项和整节文本的结果准确、无额外敏感字段。
- 多显示器、未知 EDID、无磁盘分类、虚拟设备和部分观测失败都不会产生误导性摘要；显示器的四个固定槽位保留可靠值或明确“未识别”字段。
