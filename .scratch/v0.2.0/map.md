## Decisions-so-far

1. 侧边栏沿用 ADR-0050：应用设置偏好唯一持有，`216/248/360` DIP，拖拽、键盘和跨重启恢复。
2. 自动更新检查只查询工作台本体 GitHub 正式稳定 Release；计划为关闭/启动时/每日/每周，新安装默认启动时；活动初始化操作期间跳过并补偿，不后台下载或替换。
3. 硬件信息统一为“项目 | 信息”表，显示器、键盘、鼠标和触控板均在同一张表；未分类物理磁盘、NAND 颗粒推断和资料识别不显示。显示器括号固定为无冗余标签的分辨率、Hz、内建/外接、英寸四槽，未知槽显示对应“未识别”字段而不省略。
4. CPU 中文核心构成保留零值；核显的模型、架构和 CU/EU/Xe、GPU 板卡厂商、型号/容量和“英睿达 Crucial”规范名均以可靠事实为前提。独显不显示计算单元或共享显存，普通型号去除 `(R)`/`(TM)`。
5. 键盘显示可靠的内建/外接状态，键数和内建具体类型只在可靠设备、OEM 或驱动事实存在时显示；无类型时只写“内建键盘”，不由整机型号、WMI 名称或厂商品牌推断。固定摘要行无事实显示“未识别”，多实例类别无记录隐藏；硬件文字可选择复制，但没有“复制本节”按钮或命令。
6. QQ 与 QQ 音乐为普通、默认不勾选、官方来源的 Windows 稳定桌面软件；不随包携带第三方安装器。
7. 安装采用参数化、受控 UI Automation、官方界面交互三层；未知、账户、隐私、付款和条款不自动处理，安装结果必须联合验证。
8. x64 Windows 实机是 0.2.0 安装验收门槛；任一软件验收不稳定则延期，不把未实机验证写成可用。

## Fog

- GitHub 查询实现和网络错误语义需要在 Windows 原生环境确认，不能把固定 `unavailable` 替换成不受控的网页抓取。
- QQ/QQ 音乐官方来源、稳定分支、安装文件类型和 UI Automation 身份仍需事实核对；来源失效或交互未知必须 fail-closed。
- `f2f1998` 的硬件扩展包含比当前集成基线更多的 WMI/EDID/存储推断代码；实现前必须决定哪些结构化事实保留、哪些仅从呈现移除。GPU、输入设备和品牌/型号规范化遇到缺失或冲突事实时不得补推。
- 真实多显示器、DPI、剪贴板、安装器退出/后置行为和 x64 用户验收尚未发生。
- 本轮未创建 `implementation-plan.md`，未创建 0.2.0 分支、worktree、PR、tag 或 Release。

## Exit criteria

- 所有事项 `Resolution: completed`，或经维护者明确延期后将相应事项记录为 `wontfix`/下版本承接。
- x64 构建、核心合同、Windows UI、更新查询、硬件复制和 QQ/QQ 音乐实机证据分别记录，未验证边界不被合并成“通过”。
- 只有维护者确认可用安装项和版本放行后，才允许另行进入发布流程。
